# UX の直し 1（見た目がほぼ変わらない不具合と事故防止）

2026-10-01 の UX/UI 監査と、利用者との QA で決めた範囲のうち、試作を待たずに入れるものをまとめる。
見た目が大きく変わるもの（セッション画面の組み直し、本文の表示、⌘K の集約、設定画面、ホーム、通知、ダイアログの共通の殻、初回の準備リスト）は試作を見てから別の計画にする。

ブランチは `worktree-ux-fixes-1`。
4 つの組に分け、組ごとに別の worktree で並行して実装し、このブランチへ取り込む。

## 組 A：事故を防ぐ

- A1 停止の確認。
  作業中（busy か waiting）か、シェルタブがあるときだけ ConfirmDialog を出す。
  確認の文には、作業中であることと、閉じるシェルタブの数を書く。
  休みでシェルタブが無ければ、押してすぐ止める。
  ボタンは危険色にする。
- A2 ⌘W をアプリで受ける。
  セッション画面では ⌘W で窓を閉じない。
  閉じるのはフォーカスのある枠（分割中は右の枠もありうる）のシェルタブだけで、Claude のタブでは何もしない。
  フォーカスのある枠は、枠の focusin と押したときに、その枠のタブとして Root の ref に覚え、⌘W の対象にする。
  選択中のタブは変えない。
  覚えた枠がもう画面に無ければ、選択中のタブを対象にする。
- A3 紐づけの削除の確認。
  ResolveProjectDialog の「紐づけを削除」は ConfirmDialog を挟み、プロジェクト名、未分類に戻るセッションの件数、他の端末からも消えることを書く。
  ボタンの名前を「一覧から削除」に改め、危険色にする。

## 組 B：一覧と検索の小さな不具合と色

- B1 「触ったファイル」の絞り込みを、キーワードが無くても効かせる。
- B2 検索の件数と並ぶ行の数を合わせる。「上位 50 / 132 件」と出し、末尾で続きを読み込めるようにする。
- B3 期間の絞り込みを相対の日数で持つ。「今日」は時間が経っても「全期間」の表示にならない。
- B4 一覧で、生きているもの同士を waiting、busy、idle の順に並べる（`LIVE_ORDER` を使う）。
- B5 ⌘N とヘッダーの新規ボタンが、いまの画面（project か session）のプロジェクトを最初から選ぶ。
- B6 ダイアログに高さの上限を付け、中身をスクロールさせ、下端のボタンを見えるままにする。
- B7 `--ink-3` を `#6e6d88` にし、tokens の試験に ink-3 のコントラストを加える。

## 組 C：キー操作

- C1 一覧で ↑↓ を j/k と同じに扱う。行のフォーカスとカーソルを 1 つにまとめ、Enter で別の行が開かないようにする。画面に入ったら一覧にフォーカスする。
- C2 ⌘K のカーソルに合わせて一覧をスクロールする。
- C3 ターンの目次とタブを矢印で動かせるようにする。
- C4 入力欄で Esc を押すとフォーカスが外れる。
- C5 「次の入力待ちへ」のキーを足し、キーの一覧に載せる。

## 組 D：端末の打鍵

- D1 Shift+Enter で改行する（送信しない）。
- D2 Option+ドラッグで、tmux がマウスを取っていても文字を選べる。
- D3 OSC 52 を受けて、端末の中からのコピーをクリップボードへ渡す。
- D4 ⌘+ と ⌘− と ⌘0 で端末の文字の大きさを変え、覚えておく。
