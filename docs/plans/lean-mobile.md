# スマホ版の補助ラベルと説明文を削る（強め）

2026-10-25 に利用者と決めた。
デスクトップの作り替え（`docs/plans/lean-labels.md`、PR #328）と同じ原則と線引きを、スマホ版（`packages/mobile`）に当てる。
ブランチは `worktree-lean-mobile`。

## 決まったこと

- 強さは「強め」。説明は既定で隠し、残す説明も見出しの言い直しを削って、条件、数値、例外だけにする。
- 隠した説明は、見出しの横の ⓘ を押すと、見出しのすぐ下にその場で開く（growIn、`--dur`、`--ease-out`）。もう一度押すと畳む（collapseOut、`--dur-exit`、`--ease-in`）。減らす動きの設定では動かさない。
- 受信箱の入力待ちの札の「〜のアカウントで開く ›」「Claude アプリで開く ›」は、どちらも「開く ›」にする。アカウントは札の上のタグで見せる。
- 新しい会話の画面で、まだ選べない段（プロジェクトを選ぶ前の PC、PC を選ぶ前のアカウント）は隠す。前の段を選ぶと、次の段が下に広がって現れる。「〜を選ぶと表示されます」の文は消す。

## 残す（画面に常に出す）

- 接続のエラー（キーの保存、10 台の上限、アプリが古い、QR が使えない理由、PC の応答なし）。
- 許可の案内（カメラ、通知、iOS での通知の入り方）。
- 取り消せない操作の結果（接続の解除、別の QR で接続しても今の接続は消えないこと）、紛失時の解除、QR を人に見せないこと。
- 期限と数値（QR の 5 分、残り時間、接続し直す期限、xhigh と max の使用量、応答不明の注意、最大 30 秒の待ち）。
- 「ほかのスマホには効きません」「この PC にアカウントがありません」「クイックセッションでは、パスを手で入力してください」。
- 失敗後の逃げ道（「手で入力しても、そのまま送れます」）。

## 変えるもの

- 設定
  - 「新しい会話のデフォルト」の脚注「新しい会話の画面を開いたときに、最初から選んでおく値です。」を消す。
  - 通知を止める時間の脚注は「ほかのスマホには効きません」だけ画面に残し、「このスマホの時刻で判定します」は見出しの ⓘ に入れる。
  - 接続の期限の説明は「30 日使わないと切れます」に縮めて ⓘ に入れる（90 日側は期限の行が示す）。
- 新しい会話
  - クイックセッションの副題「どの PC でも」を消す。
  - 小見出し「最近」を消す。
  - 検索欄の placeholder を「検索」にする（件数は「すべて n 件 ›」が示す）。
  - 「他 n 件（「すべて」で見る）」を「他 n 件」にする。
  - PC の副題「空き」を消す（実行中が 0 なら何も出さない）。
  - 「詳しい設定」の「すべてデフォルト」を消す（変えた値があるときだけ要約を出す）。
  - 初期プロンプトの長さの超過は「{n} 字多い」だけにする。「あと {n} 字」は残す。
  - placeholder の括弧「（/ でスキル、@ でファイル）」を消す。
  - Composer の「先に PC を選んでください」の下の「候補は、選んだ PC とアカウントから取得します。」を消す。
- 添付
  - 写真ライブラリの副題「ここから選ぶ」を消す。
  - シートの注記を「4 枚・1 枚 5 MB まで」にする（2048 px の説明を消す）。
  - 添付後の「n/4 枚 · 1 枚 5 MB まで」を「n/4 枚」にする。
- 候補のシート（SuggestSheet）
  - 空の文は「合うものなし」程度にし、「そのまま文として送ることもできます」「名前を入力すると検索できます」の重複を 1 か所にする。
  - 「問い合わせ中…1〜3 秒かかります」から「1〜3 秒かかります」を消す。
- 起動のシート（LaunchSheet）
  - 「送信中…」の文を消す（段と進みの棒が示す）。最大 30 秒の見通しは残す。
- 受信箱
  - 本文が空のときの決まり文（許可が必要です、質問があります）と、下の行の種別（許可待ち、質問）の二重をやめ、種別は下の行の小さな札 1 つにする。本文が空なら本文の行を出さない。
  - 「入力待ちの会話はありません」は「なし」程度に縮める。
- 接続（JoinScreen）
  - 完了画面の「最後に、ホーム画面に追加するとアプリのように開けます。」を消し、ボタンを「あとで」にする。
  - 読み取りの説明は「QR は表示してから 5 分有効です」だけにする（枠に合わせる文を消す）。
  - 接続の説明は前半（できること）を消し、紛失時の解除の文を残す。
  - 名前の欄のラベルの括弧「（PC の一覧に表示されます）」を消す。
- 導入の手引き（InstallGuide）
  - 太字の手順を言い直す補足（「画面下の □↑ をタップ」）を消す。ほかの補足は残す。

## 確かめ

- `npm run typecheck` と、`npx vitest run --root packages/mobile`。文言を見ている試験は新しい文言に合わせる。
- 画面は、試験の描画か、Vite の dev で開ける範囲で撮る（実データは要らない）。
