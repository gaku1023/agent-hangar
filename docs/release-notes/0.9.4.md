# Hangar 0.9.4

設定の並びを組み替え、エディタの欄を畳みました。スマホの画面の説明も ⓘ にしまいました。

## 足したこと

### 設定の並びを、使う順に組み替えました

- 目次は、一般、セッション、要約、連携、環境、クラウド同期、使用量、Hangar について、の順です。
- 新しい「セッション」には、デフォルトのモデル、Remote Control、新しいディレクトリの作成先、Claude Code に渡す設定、ステータスの自動処理、トランスクリプトの保持、アカウントをまとめました。
- 「ツール」は「環境」に、「要約エンジン」は「要約」になりました。「情報」は「使用量」と「Hangar について」に分け、バージョンと更新は一番下の「Hangar について」にあります。

### エディタの欄は、選んでいる 1 本だけを出すようにしました

- ほかのエディタは「ほかのエディタ」に畳んであり、開くと見つかったものが上に並びます。選ぶと閉じます。

### スマホの画面の説明を ⓘ にしまいました

- 設定の説明は見出しの横の ⓘ を押すと、その場で開きます。新しい会話では、PC とアカウントの段が、前を選ぶと現れます。

## スマホの新しい画面を使うには

- スマホの画面の直しは、Worker を更新すると使えます。更新しなくても、PC の同期とスマホはこれまでどおり動きます。
- 更新するときは、クラウドを作成した PC で、リポジトリを clone したディレクトリから `npm run hangar -- setup cloud` を実行してください。同じクラウドのまま Worker だけを更新し、データやリカバリーキーはそのままです。
- 更新したら、スマホのホーム画面の hangar を一度閉じて開き直してください。
