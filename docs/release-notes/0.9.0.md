# Hangar 0.9.0

クラウド同期の仕組みを作り替え、同期の中身を暗号化して、PC の追加を参加コードと承認に変えました。

## 更新の前に

クラウド同期を使っているときは、クラウドの再構築が必要です。0.9.0 は 0.8.x までのクラウドと同期できず、移行の道もありません。同期の互換のバージョンを上げたので、0.8.x と 0.9.0 の PC は混在できません。同期していない PC は、そのまま上げられます。

1. 0.8.x のうちに、すべての PC で「今すぐ同期」を押します。続けて、設定 › クラウド同期 の「Claude Code の設定の同期」を切ります。再構築の間に、古い設定で `~/.claude` を上書きしないためです。
2. すべての PC を 0.9.0 に上げます。上げた PC は、再構築が終わるまで同期を始めず、設定の画面に「クラウドの再構築が必要です」と表示します。
3. クラウドを作成した PC で `hangar cloud teardown` を実行して、Worker と D1 と R2 を削除します。他の PC の分を含め、R2 にしかないトランスクリプトは、削除の前に `~/.agent-hangar/remote/` へダウンロードします。削除は元に戻せません。
4. 同じ PC で `hangar setup cloud` を実行します。最後に表示するリカバリーキーを保存して、暗号鍵の末尾 4 文字を入力すると、setup が完了します。入力が合うまで、setup は終わりません。
5. 他の PC は、設定の「参加コードで参加」から再参加します。スマホは、PC で QR を表示して接続し直します。
6. 各 PC が、手元のデータを新しいクラウドに上げ直します。D1 の書き込みが 1 日の無料枠を超えると、翌日まで同期が止まります。共有のデータが多いときは、PC ごとに日を分けて参加させてください。
7. 設定の同期のスイッチを入れ直します。適用の前に、上書きされる内容の一覧を確認します。

- `hangar setup cloud` では、0.8.x と同じ Worker の名前を使ってください。名前（URL）を変えると、スマホのホーム画面のアイコンが古い接続先を指したままになり、ホーム画面に追加し直す必要があります。
- 古い R2 にスマホの画像が残っていると、teardown のバケットの削除が止まります。そのときは表示される案内に従って、Cloudflare のダッシュボードで空にしてください。
- 0.9.0 で開くと、手元のデータベースが新しい形に上がります。0.8.x に戻すことはできません。

手順の細部と注意は [クラウド同期の使い方](https://github.com/gaku1023/agent-hangar/blob/main/docs/cloud-sync.md#090-への作り直し) にあります。

PC の一覧から、「最後の IP」と「おおよその場所」の表示をなくしました。Worker も IP と所在地を保存しません。`hangar setup cloud --rotate-secret` もなくなりました。PC を締め出すときは、その PC を解除します。

## 足したこと

### 参加コードと承認で、PC を追加できます

- 参加済みの PC の「PC を追加」で、8 文字の参加コードを表示します。コードは 5 分で期限が切れ、1 回しか使えません。
- 新しい PC が参加コードを入力すると、参加済みの PC に通知が出ます。両方の PC の確認コードが同じなら「承認」します。参加コードを人に見られても、承認しなければ参加できません。
- 参加トークンはなくなりました。人が長い秘密の文字列を運ぶ必要はありません。

### 同期の中身を、PC の鍵で暗号化します

- セッションの題、要約、TODO、ノート、ファイルのパス、PC の名前を、暗号化してから D1 と R2 に置きます。Cloudflare からは読めません。
- 暗号鍵は人に見せない乱数で、参加済みの PC が新しい PC の公開鍵に封じて渡します。

### リカバリーキーで、すべての PC を失っても取り戻せます

- setup が、リカバリーキーを 1 度だけ表示します。パスワードマネージャーに保存してください。
- PC が 1 台でも残っていれば、設定の「リカバリーキーを再発行」で新しいリカバリーキーを発行できます。確認が済むと、古いリカバリーキーでは復元できなくなります。
- すべての PC を失ったときは、新しい PC で `hangar recover` を実行します。

### PC を解除すると、暗号鍵を再生成します

- 解除した PC は、それ以降のデータを復号できません。R2 の既存のファイルは、他の PC が読めるままです。
- 解除された PC は、参加コードで再参加できます。

### スマホの解除を、1 クリックで行えます

- スマホの接続は、スマホの公開鍵で行います。0.8.x で接続したスマホは、接続し直してください。
- 解除は 1 クリックで、5 秒のあいだ「元に戻す」で取り消せます。他のスマホの接続は切れません。
- スマホのトークンは、30 日使わないと切れます。接続から 90 日で、再接続が必要です。

### スマホから起こした会話に、「スマホから」のラベルが付きます

- セッションの一覧の行と見出しに、ラベルを付けます。PC には、右下の通知も出ます。
- Bypass permissions で起こした会話は、ラベルを赤くします。
