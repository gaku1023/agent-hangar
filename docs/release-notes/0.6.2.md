# Hangar 0.6.2

## 足したこと

### ⌘R（Windows は F5 か Ctrl+Shift+R）で画面を再読み込みします

- macOS は ⌘R、Windows は F5 と Ctrl+Shift+R で、アプリの画面を読み込み直します。
  Ctrl+R はターミナルの履歴の検索に残しています。
- ターミナルや入力欄にフォーカスがあっても効きます。
  読み込み直しても、tmux（Windows は psmux）の中のセッションと Claude は止まりません。
- macOS のメニューの「表示」に「再読み込み」を足しました。
  ショートカットの一覧にも載せました。

### ⌘＋クリック（Windows は Ctrl＋クリック）でターミナルのリンクを開きます

- ターミナルに出た URL と、OSC 8 のハイパーリンクを、macOS は ⌘＋クリック、Windows は Ctrl＋クリックで既定のブラウザに開きます。
  素のクリックは、これまでどおり選択とフォーカスです。
- 下線とポインタは、⌘（Ctrl）を押している間だけ出ます。
- 開くのは http と https だけです。

### セッション画面から「宛先」の 1 行をコピーできます

別の Claude Code のセッションに「このセッションに送って」「様子を見て」と頼むための 1 行を、セッション画面からコピーできます。

- (i) の先頭に「宛先」の行（終わったセッションは「ID」）とコピーのボタンを足しました。
- 「…」のメニューの「宛先をコピー」と、⌘⇧C（Windows は Ctrl+Alt+C）でもコピーできます。
  Ctrl+Shift+C はターミナルのコピーなので使いません。
- コピーするのは「hangar のセッション「<名前>」（宛先: <宛先>、session_id: <ID>）」の形の 1 行です。
  渡された Claude は、この宛先に SendMessage で送れます。
  終わったセッションは宛先を外して「終了」と添えます。
- MCP の `get_transcript` で、ほかのセッションのトランスクリプトも読めるようにしました。
  書き込みの道具は、これまでどおり自分のセッションだけです。

### Claude Code から作者へ不具合や要望を送れます

Claude Code の会話の中から、hangar の不具合の報告や要望を、このリポジトリの GitHub Issues に送れます。

- `draft_issue_report` が下書きを作ります。
  hangar と Claude Code の版、OS を添え、登録したプロジェクトのパスと名前、ホームのパス、ユーザー名、ホスト名、メールアドレス、トークンらしい文字列を伏せます。
  似た Issue が開いていれば、それも示します。
- 下書きを見て送ると決めたときだけ、`submit_issue_report` が下書きをそのまま送ります。
  利用者の確認（`confirmed`）が無ければ送りません。送るときに Claude が本文を書き換えることはできません。
- `gh` でログインしていれば `gh issue create` で送ります。
  していなければ、中身を入れた Issue の作成画面をブラウザで開き、送信は利用者が押します。
- 下書きは 30 分で消えます。

## 直したこと

### 終わったセッションを、最新の返答を畳まずに開きます

- 終わったセッションを開くと、最後の返答が「全文を表示（残り N 行）」で畳まれていました。
  0.6.2 からは、いちばん新しい返答は初めから全部出します。
- セッション画面を開いたら、ターミナルにフォーカスを移します。
  サイドバー、一覧、通知、戻る・進む、リンクのどこから開いても同じです。
  ダイアログが開いている間は移しません。

### / のスキルの候補を、文の途中でも出します

- 初期プロンプトの欄で、`/` の候補を欄の先頭だけでなく、空白か改行の直後ならどこでも出します。
  パスや URL の途中の `/` では出しません。
- 「スキル」ボタンは、欄の先頭ではなくカーソルの位置に `/` を入れて候補を開きます。
  「ファイル」ボタンも同じです。
- 文の途中に置いた `/スキル` は、Claude がスキルとして呼び出します。

### Windows PowerShell 5.1 の statusline から使用量が送られなかったのを直しました

- 日本語の Windows PowerShell 5.1 で、statusline のスクリプト（.ps1）に入れた hangar の行が読み違えられ、使用量が送られず、ヘッダーの使用率が出ませんでした。
  5.1 は BOM の無い .ps1 を日本語の文字コード（CP932）で読むので、日本語のコメントが次の行まで食っていました。
- hangar が入れる行を ASCII の文字だけにしました。
  前の版で入れた行は、入れ直すときに差し替え、外すときにも消します。
- 標準入力をバイトで読み、UTF-8 として解釈するようにしました。日本語を含む内容も化けません。
- スクリプト自身が標準入力をバイトで読んでいるときは、自動では入れません（先に読み切ると、元のスクリプトが何も読めなくなるため）。案内の文で手で入れる方法を示します。

### Windows のトラックパッドのスワイプで、すぐに戻る・進むが動きます

- 0.6.1 では、Windows でトラックパッドを払って指を離したあと、慣性のスクロールが止まるまで（2 秒ほど）戻る・進むが動きませんでした。
  0.6.2 からは、指を離した瞬間に動きます。
- 1 回の払いで 2 回戻ることはありません。
  指を離さない払いや、離した瞬間を知らせない機器では、これまでどおり払う手が止まったところで動きます。

### Claude Code 2.1.300 に合わせました

- Claude Code 2.1.300 から、トランスクリプトに API の要求の記録の行（1 行が数十 KB）が書かれるようになりました。
  hangar はこれを知らない行として残し、会話を開くたびに読み直していました。
  0.6.2 からは読み捨てるので、長い会話を開くのが軽くなります。
  会話の本文は別の行にあるので、表示は変わりません。
- `~/.claude` の `remote-settings.json.synced-at` を、アカウントごとの項目として扱います。
- 互換を確かめた Claude Code の版を 2.1.300 にしました。

### Windows で、古い psmux を使っていると知らせます

- psmux 3.3.5〜3.3.8 では、Claude Code が動いているペインでホイールを上へ回すと、画面が遡らずに、Claude Code の入力欄に過去のプロンプトが出ます。
  psmux がホイールを ↑ キーに変えて Claude Code へ送るためです（psmux 3.4.0 で直っています）。
- 0.6.2 からは、psmux が 3.4.0 より古いと、ホームの「セットアップの確認」に注意の行を出します。
  セッションを始めるのは止めません。
- 設定の psmux の節には「更新が必要」の札と、症状、上げる 1 行のコピー、「上げたら再確認」を出します。
  `hangar setup` も、古いときは注意と上げる 1 行を添えます。
- 上げるときは、hangar の外の PowerShell で次を実行してください。
  psmux を止めるので、実行中のセッションは全部止まります。

  ```powershell
  Get-Process psmux -ErrorAction SilentlyContinue | Stop-Process -Force; winget upgrade marlocarlo.psmux; tmux -V
  ```
