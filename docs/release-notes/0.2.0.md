# Hangar 0.2.0

## v0.1.0 から入れ替える人へ（先にお読みください）

v0.1.0 には自動更新が無いので、手で入れ直します。
この dmg を開き、`Hangar.app` を `Applications` へドラッグして、古い `Hangar.app` を置き換えてください（先に Hangar を終了します）。
`~/.agent-hangar` の中身は、そのまま引き継がれます。

0.2.0 から、署名が変わります。
v0.1.0 は署名なしで、0.2.0 は自作の証明書で署名します。
入れ直したあとの初回だけ、次の 2 つが起きます。

- 「"Hangar" は開いていません」という警告が、もう一度出ます。
  「完了」で閉じ、システム設定の「プライバシーとセキュリティ」で、「…"Hangar"がブロックされました。」の行の「このまま開く」を押します。
  README の「インストール（配布版）」の 3 段目に、手順を書いています。
- ローカルネットワークなどの許可を、一度だけ取り直します。

この入れ直しのあとは、更新のたびに警告も許可の取り直しも出ません。

## 新しくなったこと

### 自動更新

- 設定の「更新」の節と右下の札が、新しい版を知らせます。
  起動したときと、その後 6 時間おきに確かめます。
  「ダウンロードしてインストール」を押すと、取得して入れ替え、再起動したあとにセッションの続きを表示します。
  tmux の中のセッションは止まりません。
- 更新は、署名を確かめてから入れます。

### 許可が保たれる署名

- Hangar を入れ替えても、ローカルネットワークなどの許可が外れなくなりました。
  これまでの未署名の build は、入れ替えるたびに別のアプリとして扱われていました。

### 配布

- macOS は、dmg で配ります。zip は予備です。どちらにも checksum を添えています。
- 試しの版（Pre-release の印の付いたもの）は、確かめが済むまでの間だけ置きます。ふだんは Latest の版を使ってください。

### Windows 11（x64）

- Windows のインストーラ（`Hangar-v0.2.0-windows-x64-setup.exe`）を添えました。
  管理者権限は要らず、`%LOCALAPPDATA%\Hangar` に入ります。
  署名していないので、SmartScreen が出たら「詳細情報」から「実行」を選びます。
- tmux の代わりに psmux を使います。先に `winget install -e --id marlocarlo.psmux` で入れてください。Node 22 も要ります。
- 入力待ちの通知、外のターミナル（Windows Terminal）、`hangar open`、`hangar` コマンドの PATH への追加が使えます。
- ターミナルで打った `claude` の包み（`hangar shell install`）は、Windows では作りません。セッションは Hangar の画面から始めます。

### 起動まわり

- Node が見つからないときや、4177 のサーバの版が合わないときは、読み込み画面が理由と直し方を出します。
- アプリは、Homebrew、nvm、fnm、Volta、mise、asdf、nodenv の Node 22 を見つけます。見つからないときは設定の「Node のパス」で指定します。
- 2 つ目を起こしたときは、窓を増やさず、動いている窓を前へ出します（Windows）。

## 前提

- macOS 13 以降の Apple silicon、または Windows 11 の x64。
- Node 22、tmux（Windows は psmux）、Claude Code（`claude`）。アプリは Node を同梱していません。
