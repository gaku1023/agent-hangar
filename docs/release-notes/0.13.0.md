# Hangar 0.13.0

Codex と opencode が、Claude Code の指示と MCP を使えるようになりました。Codex もアカウントを切り替えられます。

## 足したこと

### Codex と opencode が Claude Code の指示を読むようになりました

- 起動するときに、~/.claude/CLAUDE.md と、作業ディレクトリの CLAUDE.md・CLAUDE.local.md を Codex と opencode に渡します。同じ場所に AGENTS.md があれば、そちらを優先します。
- Codex や opencode の設定ファイルは書き換えません。設定の Codex と opencode の節にある「Claude Code の指示を渡す」で切り替えられます（既定は有効）。

### Claude Code の MCP を Codex と opencode に渡せるようになりました

- Claude Code に登録した MCP サーバーを、それぞれの形式に直して起動時に渡します。既定は無効で、設定の「Claude Code の MCP を渡す」で有効にします。
- 有効にすると、渡すものと渡さないもの（理由つき）が一覧で表示されます。

### Codex のアカウントを切り替えられるようになりました

- Claude Code と同じように、Codex のアカウントを追加し、会話ごとに使うアカウントを選べます。
- 設定の画面は、エージェントごとの節に分かれました。

## 直したこと

- Windows で開発者モードが無効だと、2 つ目のアカウントのディレクトリを共有できず、起動できませんでした。いまはディレクトリを共有したうえで起動し、共有できなかったファイルと開発者モードの入れ方をアカウントの札に表示します。
- 確認済みのバージョンを Claude Code 2.1.312、Codex 0.165、opencode 2.2 に上げました。
