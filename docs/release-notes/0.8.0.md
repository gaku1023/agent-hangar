# Hangar 0.8.0

スマホから、全部の PC の会話の一覧を見て、新しい会話を始められるようにしました（試験的）。

## 更新の前に

スマホ版を使うには、Worker の入れ替えが要ります。上げない間も同期は今までどおり動き、スマホ向けのものは何も書きません。

1. 同期しているすべての PC を 0.8.0 に上げます。古い版の PC では、つないだスマホが PC の一覧に PC として並びます。
2. clone した場所で `hangar setup cloud` をやり直して、Worker を入れ替えます。スマホの画面と、起動を速くする仕組み（Durable Object）も、このとき一緒に配ります。やり直さない Worker では、スマホからの起動は今までどおり最大 30 秒かかり、「/」と「@」の候補、画像、effort は使えません。
3. DB の版が上がります。上げた後は、前の版に戻せません。
4. スマホをなくしたら、すぐに設定の「クラウド同期」から解除してください。スマホからは、選んだ権限モードの会話を、承諾なしに全部の PC で始められます。

## 足したこと

### スマホで、入力待ちの会話が一目で分かります

- 全部の PC、全部のアカウントの会話を 1 つの一覧に並べます。入力待ちは、問いや許可を求めているコマンドと、待った時間つきで先頭に出ます。
- 続いて、実行中の会話、今日のリマインダー、今日終わった会話が並びます。
- 各行にアカウントの札が付きます。行をタップすると、そのアカウントの Claude アプリ（Remote Control）で開きます。

### スマホから、PC を選んで新しい会話を始められます

- プロジェクトは、クイックセッションと最近の 5 件、検索、「すべて」から選びます。
- 権限モード、モデル、effort は「詳しい設定」に畳みました。閉じている間は、選んだ内容を 1 行で示します。
- 初期プロンプトに、PC の画面と同じ「/」（スキルとコマンド）と「@」（ファイル）の候補が出ます。写真やカメラの画像も、4 枚まで付けられます。
- 「始める」の後は、送信、PC で受信、開始の順に、下からのシートで進み具合を見せます。始まった会話は、そのシートから開けます。

### 呼び鈴で、起動と候補の応答が速くなります

- Worker に呼び鈴を足し、PC とつなぎっぱなしにしました。スマホからの起動を、PC がすぐ受け取ります。
- 「/」と「@」の候補は、1〜3 秒で返ります。問い合わせの中身と画像は、スマホで暗号化し、Worker では読めません。
- 画像は、PC が受け取ったら Worker から消えます。受け取られなかった画像も、1 日で消えます。

### スマホの入口を、ホーム画面に追加する形に整えました

- iPhone の Safari で開くと、接続より先に「ホーム画面に追加して、そこから開く」を案内します。
- ホーム画面から開いたアプリでは、アプリの中で QR を読んで接続します。接続コードを貼り付ける欄も残しています。

### 設定の「クラウド同期」から、QR でスマホを接続します

- QR は 5 分で使えなくなり、1 回しか使えません。スマホには参加の秘密を渡しません。
- 接続したスマホは一覧に並び、そこから解除できます。

### hangar で起動した会話を、Remote Control につないで起動します

- 設定の「連携」の「Remote Control を付けて起動する」で切り替えます。最初は入です。
- claude.ai でログインしたアカウントだけで有効です。API キーのアカウントでは付けずに起動します。

## 直したこと

- Windows で、画面を開かないと Remote Control が付かずに起動していました。起動の時にアカウントのログインを読むので、開かなくても付きます。
- 画面、CLI、起動の画面の日本語の文言を、用語集にそろえて見直しました。「入力待ち」「実行中」「クイックセッション」「リマインダー」など、呼び方を統一しています。

## まだ確かめていないこと

- iPhone で「ホーム画面に追加」した後も接続が残るか。残らないときは、アプリの中の「QR を読む」か「接続コードを貼り付け」で接続し直せます。
- iPhone のホーム画面のアプリで、カメラ（QR と撮影）と写真の選択が使えるか。
- 実物のクラウドで、呼び鈴の接続が数時間つながり続けるか。Windows の PC からの呼び鈴も未確認です。
