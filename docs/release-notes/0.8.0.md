# Hangar 0.8.0

スマホから、全部の PC の会話の一覧を見て、新しい会話を始められるようにしました（試験的）。

## 更新の前に

スマホ版を使うには、Worker の入れ替えが要ります。上げない間も同期は今までどおり動き、スマホ向けのものは何も書きません。

1. 同期しているすべての PC を 0.8.0 に上げます。古い版の PC では、つないだスマホが PC の一覧に PC として並びます。
2. clone した場所で `hangar setup cloud` をやり直して、Worker を入れ替えます。スマホの画面も、このとき一緒に配ります。
3. DB の版が上がります。上げた後は、前の版に戻せません。
4. スマホをなくしたら、すぐに設定の「クラウド同期」から解除してください。スマホからは、選んだ権限モードの会話を、承諾なしに全部の PC で始められます。

## 足したこと

### スマホで、自分を待っている会話が一目で分かります

- 全部の PC、全部のアカウントの会話を 1 つの一覧に並べます。入力待ちは、問いや許可を求めているコマンドと、待った時間つきで先頭に出ます。
- 続いて、動いている会話、今日戻る会話、今日終わった会話が並びます。
- 行を押すと、その会話を Claude アプリ（Remote Control）で開きます。

### スマホから、PC を選んで新しい会話を始められます

- プロジェクト、PC、アカウント、権限モード、モデル、最初の指示を選んで始めます。
- PC が受け取るまで最大で 30 秒ほどかかります。

### 設定の「クラウド同期」から、QR でスマホを接続します

- QR は 5 分で使えなくなり、1 回しか使えません。スマホには参加の秘密を渡しません。
- 接続したスマホは端末の一覧に並び、そこから解除できます。

### hangar で起動した会話を、Remote Control につないで起動します

- 設定の「連携」の「Remote Control を付けて起動する」で切り替えます。最初は入です。
- claude.ai でログインしたアカウントだけで有効です。API キーのアカウントでは付けずに起動します。

## まだ確かめていないこと

- iPhone で「ホーム画面に追加」した後も接続が残るか。残らないときは、アプリの中の「QR を読む」か「接続する文字列を貼る」で接続し直せます。
