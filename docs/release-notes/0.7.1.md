# Hangar 0.7.1

## 更新の前に（クラウド同期を使っている人へ）

この版は、クラウド同期の作りを変えた版（互換の版 6）です。
古い版のアプリや Worker とは同期しません。
データは消えませんが、次の 2 つがそろうまで、その PC の同期は止まります。

1. 同期しているすべての PC のアプリを 0.7.1 にする。
2. クラウドを作った PC で、リポジトリを `v0.7.1` にしてから `npm run hangar -- setup cloud` をもう一度実行し、Worker を入れ替える。

止まっている間は、設定のクラウド同期の節に理由と直し方が出ます。
アプリが新しくて Worker が古いときは「`hangar setup cloud` をもう一度実行」、アプリが古いときは「この PC の hangar を更新」です。
入れ替えると、各 PC は最初の同期で共有のデータを 1 回だけ全部取り直します。

## 足したこと

### ほかの PC で動いている会話を、この PC で引き継げます

- 「この PC で再開」が、ほかの PC で実行中の会話にも使えるようになりました。
  相手の Hangar に停止を頼み、最後のトランスクリプトが届いてから再開するので、会話は分かれません。
- 相手から 90 秒返事がなければ、取り消す、もう少し待つ、このまま引き継ぐ、から選べます。
  相手の応答がすでに途絶えていれば、待たずに確認して引き継ぎます。
- 引き継がれた側の PC では、会話の見出しの下に引き継ぎ先が出ます。
  残った claude は、次に Hangar が起動したときに停止します。

### セッション ID だけをコピーできます

- セッションの「…」メニューと、一覧の行のメニューに「セッション ID をコピー」を足しました。
  `claude -r <ID>` での再開に使える Claude Code の ID だけをコピーします。
- ショートカットは ⌘⌥C（Windows は Ctrl+Alt+Shift+C）です。

## 変えたこと

### クラウド同期の読み書きを大きく減らしました

- Cloudflare の D1 の読み取りが、データが溜まるほど増え続ける作りでした。
  同期が 1 日で無料枠（アカウント全体で 500 万行）を超えることがあり、超えると同じアカウントのほかの D1 まで翌日まで止まります。
- 変更の記録を溜めて掃除する作りをやめ、共有のデータそのものに連番を振る作りにしました。
  読み取りは、実際に変わったデータの量にだけ比例します。
- 30 秒ごとに送っていた「動いている」の印と、会話の最後の動きの時刻の細かい更新を、送らないか間引くようにしました。
  書き込みも大きく減ります。
- ほかの PC が動いているかは、その PC が最後に Worker へ接続した時刻で判断します。
  3 分つながっていなければ「応答がありません」になります。
  この PC 自身の同期がしばらく通っていないとき（起動の直後や、同期が止まっているとき）は、相手を「応答なし」とはみなしません。
- 落ちたまま起動していない PC の会話が、ほかの PC でずっと「実行中」のまま残ることがなくなりました。

### 動いている間は、メニューに「削除…」を出しません

- サイドバーの右クリックなど、セッションのメニューで、動いている会話には「停止」だけを出します。
  止まると「削除…」に入れ替わります。

## 直したこと

- 別の画面へ移ってから戻ると、ターミナルで長く変換したときに、変換中の文字が 1 字ずつ縦に並ぶことがありました。
