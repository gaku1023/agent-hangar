# Hangar 0.11.1

ヘッダの使用量に Codex が加わり、MCP でほかの会話を操作できる範囲が広がりました。ペインを閉じるときの動きなども直しています。

## 足したこと

### エージェントからほかの会話を操作できるようになりました

- MCP に、会話の停止・再開・削除と、会話へのメッセージの送信・画面の読み取りを行うツールが加わりました。削除は毎回確認を求めます。
- MCP で会話を始めるときに、worktree と追加のフォルダを指定できるようになりました。

### MCP で始めた会話が、呼び出し元のアカウントを引き継ぐようになりました

- `create_session` で会話を始めると、呼び出し元の会話と同じアカウントで起動します。`account` で別のアカウントを指定することもできます。

### ヘッダの使用量に Codex の使用量も表示されるようになりました

- Codex を有効にしていると、ヘッダの使用量の表示に Codex の項目が加わります。

### 使っていない LM Studio のモデルを自動でアンロードできるようになりました

- Hangar が読み込んだモデルは、会話を止めてから設定した時間が過ぎるとアンロードされます。Hangar 以外で読み込んだモデルには影響しません。

## 直したこと

- 3 つ並べたペインの 1 つを閉じると、残りのペインまで消える問題を直しました。
- ペインを分けたり閉じたりするときに、動きが引っかかったり画面が一瞬白くなったりする問題を直しました。
- Codex のモデルの一覧が画面からはみ出す問題を直しました。今は画面の中に収まり、過去のモデルは折りたたんで表示されます。
- Codex の会話を再開すると、起動に失敗することがある問題を直しました。
- MCP で取得した会話の再開コマンドが、Codex と opencode の会話でも正しく動くようになりました。
- 試しの版（rc）で、設定のリリースノートが表示されない問題を直しました。
- エージェントの並び順を Claude Code、Codex、opencode にそろえました。
- サイドバーのペインの番号と「実行中」の見出し、アカウントの表示の右上の小さな印を外し、表示をすっきりさせました。
