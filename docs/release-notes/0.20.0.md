# Hangar 0.20.0

別の PC で動いている Claude Code の会話を、この PC からチャットの形で読み、続けられるようになりました。

## 更新の前に

別の PC の会話とやり取りするには、使う PC をすべて 0.20.0 に上げ、Worker を更新してください。更新しなくても、同期・スマホ・別の PC への起動はこれまでどおり動きます。

1. 使う PC をすべて 0.20.0 に上げます。
2. クラウドを作成した PC で、リポジトリを clone したディレクトリから `npm run hangar -- setup cloud` を実行します。データやリカバリーキーはそのままで、同じクラウドの Worker だけが更新されます。

- 相手の PC が 0.19 以前のままなら、これまでどおり読み取り専用のトランスクリプトで表示します。

## 足したこと

### 別の PC の会話を、チャットの形で読めるようになりました

- サイドバーやプロジェクトの画面で、別の PC で動いている Claude Code の会話を開くと、返答・道具の行・許可や質問の札がチャットの形で並びます。新しい返答は数秒で足されます。
- 見出しの札に、会話が動いている PC の名前が出ます。

### 別の PC の会話に、この PC から送れるようになりました

- 入力欄に打って送ると、相手の PC の会話に渡ります。画像の添付と、`@` で相手の PC のファイルを指すこともできます。
- 相手が作業中のときは文を預かり、ターンが終わってから渡します。渡る前なら取り消せます。相手の入力欄に打ちかけの文があるときは渡さず、10 分たっても渡せなければ取り下げます。
- 相手の会話が止まっているときは、「{PC 名} で再開して送る」で再開してから渡します。
- 「中断」で、相手のターンを止められます（Esc と同じ）。

### 別の PC の会話の許可と質問に、この PC から答えられるようになりました

- Bash の許可、ファイルの読み書きの許可（hangar から起動した会話）、AskUserQuestion の単一選択・複数選択・自由入力に答えられます。
- 答える前に、相手の PC で画面を読み、札が同じであることを確かめてからキーを打ちます。ほぼ同時に両方の PC で答えたときは、片方だけが通ります。
- MCP の道具の許可など、この PC からは答えられない札には、相手の PC で答えるよう案内を出します。

### 別の PC からの操作を受けない設定を足しました

- 設定の「他の PC からの送信を受ける」を切ると、別の PC からは読めますが、送る・答える・中断はできなくなります。設定は PC ごとで、同期しません。

## 直したこと

### エージェントへの知らせが、許可や質問の答えとして入り込まなくなりました

- 別の PC への起動の結果や、起動した会話の報告は、会話が許可や質問の札を出しているあいだ預かり、閉じてから渡します。
- 渡せないまま 10 分たったときは、預かっていることを一度だけ通知します。

### 別の PC への起動で、`permission_mode` に `default` を指定できるようになりました

- これまでは、起動を頼んだあとで相手の PC に「リクエストの中身を読めませんでした」と断られていました。受けられない値は、頼む前にその場で断ります。

### 確かめた版を Claude Code 2.1.319、Codex 0.167 に上げました

- Claude Code 2.1.319 で増えた会話ログの行とファイルを、設定の互換性の表が「変更点」として出していました。今はこれらを既知の形式として扱い、変更点として出しません。

### Windows で、自動更新に失敗しても Hangar が止まったままにならなくなりました

- インストーラの起動に失敗したら、サーバーと窓を元に戻します。前は、窓が隠れサーバーが止まったままになることがありました。
- Smart App Control などにブロックされたと見られるときは、その旨と「リリースページを開く」のボタンを出します。手動でインストールしてください。

### Windows で、終わったはずの Claude Code の会話が実行中のまま残ることがなくなりました

- 再起動のあと、Windows が同じプロセス ID を別のプログラムに使い回すと、終わった会話を実行中と見誤ることがありました。プロセスの起動時刻で見分けるようにしました。

### 会話の画面で押した Ctrl+B が、サイドバーを閉じずにターミナルへ届くようになりました

- フォーカスがペインの枠などにあるときに Ctrl+B を押すと、サイドバーが閉じていました。いまは Claude Code の「ctrl+b to run in background」や psmux の prefix としてターミナルへ送ります。
- サイドバーの開閉は、会話の画面では Ctrl+Shift+B を使ってください。ほかの画面では、これまでどおり Ctrl+B で開閉できます。

### 通信先の説明を実際の動きに合わせました

- issue の下書きの道具が、重複を探すために題名の語を GitHub の検索へ送ることを、説明に書きました。
- スマホの頁の「Remote Control を付けて起動する」の案内が、設定の今の場所（「Claude Code」の節）を指すようにしました。
