# Hangar 0.7.0

## 上げる前に

### 同期しているすべての PC を 0.7.0 に上げてください

- 0.7.0 で、クラウドに同期する列が増えました（セッションを移したプロジェクトと、削除の印）。
- 0.6.3 以前の PC は、この列を知りません。
  古い版の PC がセッションのステータスを書くと、移した先のプロジェクトや削除の印がクラウドから消えることがあります。
- 新しい版の PC が次に同じセッションを書けば元に戻りますが、同期しているすべての PC を 0.7.0 に上げてから使ってください。

## 追加したこと

### セッションを別のプロジェクトへ移せます

- セッションのメニューの「プロジェクトを変更…」で、移動先のプロジェクトを選びます。
- 変わるのは hangar での分類だけです。
  トランスクリプトと、再開するディレクトリはそのままです。
- 移した先は、インデックスの再構築や自動の振り分け、同期で元に戻りません。
- 移した先は同期しているほかの PC にも届きます。

### セッションを削除できます

- セッションのメニューの「削除…」で、確認のあとにトランスクリプトを OS のゴミ箱へ移動し、hangar から削除します。
  サブエージェントのトランスクリプトも一緒に移動します。
- 同期しているほかの PC からも削除されます。
- ゴミ箱から戻すと、hangar にも戻ります。
  ほかの PC にも、もう一度届きます。
- クラウドにある写しは、削除から 30 日後に消えます。
- 実行中のセッションは削除できません。
  先に停止してください。
- ゴミ箱へ移動できなかったときは、何も変更しません。
- 使用量の集計からは消しません。

### どこからでも同じセッションのメニューを開けます

- ホームの一覧、プロジェクト画面、ホームの帯、サイドバーで、行を右クリックするか、「⋯」をクリックするか、`.` を押すと、同じメニューを表示します。
- メニューには、4 つのステータス（現在のものに ✓）、「プロジェクトを変更…」、「停止」、「削除…」があります。
- プロジェクト一覧の行も、右クリックか `.` で、行の「⋯」と同じメニューを表示します。

### セッション画面の見出しにステータスを表示します

- 見出しの主ボタンの左に、プロジェクト画面と同じステータスを表示します。
  クリックすると、その場でステータスを変更できます。
- Paused を選ぶと、リマインダーの日付を選ぶダイアログを開きます。

### クイックセッションをすべての PC で 1 つにまとめます

- これまで、クイックセッションのプロジェクトは PC ごとに別でした。
  0.7.0 からは、同期しているすべての PC で 1 つのプロジェクトにまとめます。
- 新しいクイックセッションは `~/.agent-hangar/quick-sessions`（Windows は `%USERPROFILE%\.agent-hangar\quick-sessions`）に作成します。
- 前の保存先 `~/.agent-hangar/scratch` は移動しません。
  その下の会話は、これまでどおり表示、再開、プロジェクトへの昇格ができます。
- ほかの PC で始めたクイックセッションをこの PC で再開すると、この PC の保存先に同じ名前の空のディレクトリを作成して、そこで再開します。
  再開の確認に、そのことを 1 行で表示します。

### Claude Code のディレクトリの信頼を hangar が設定します

hangar から Claude を起動したときに、Claude Code の信頼の確認で止まらないようにしました。

- クイックセッションの保存先は、hangar が自動で信頼済みにします。
- 作業ディレクトリ（新しいディレクトリの作成先）は、同意したときだけ信頼済みにします。
  セットアップのすゝめでは、Claude が同意を取ってから次のコマンドを実行します。自分で実行しても使えます。

```sh
hangar workspace set <ディレクトリ> --trust [--dry-run]
```

- Claude Code の信頼は、親のディレクトリから git のリポジトリの中には及びません。
  そのため、起動のたびに、いちばん近いリポジトリのルートも信頼済みにします。
- ホームディレクトリとその上、ファイルシステムのルートは信頼済みにできません。
  その下のすべてが信頼済みになるためです。

### アカウントが 1 つでもヘッダーにアカウントのメニューを表示します

- アカウントが 1 つのときも、2 つ以上のときと同じ表示（色の点、名前、使用量、▾）をヘッダーに出します。
- クリックすると、使用制限がリセットされる時刻を表示します。
  下の段から「アカウントを追加」と「アカウントの設定」を開けます。

## 変えたこと

### 終わったセッションの画面を読みやすくしました

- 続けて呼んだツールを「Bash ×5」のような 1 行にまとめます。
  クリックすると、それぞれの呼び出しを開きます。
  失敗があれば「失敗 N」を表示します。
  詳細表示のあいだは、これまでどおり 1 行ずつ表示します。
- 冒頭の欄をなくし、見出しの下に 1 行で、終了、ターン、トークン、費用、git、変更したファイル、アーティファクト、PR を表示します。
- 要約は、右の欄の目次の上に表示します。
  自動の要約しかないときは表示しません。
- 要約が無く、ターンが 2 つ以下のときは、右の欄を折りたたんで開きます。
  開閉はその画面だけのもので、設定は変更しません。
- Claude の返答を途中で折りたたまず、全文を表示します。
  長い貼り付けのプロンプトと思考は、これまでどおり折りたたみます。

### サイドバーの並べ替えに動きを付けました

- ドラッグした行が浮き、ほかの行がよけ、離すと収まります。
- ドラッグの途中で一覧が変わったときは、並べ替えを取り消します。

### 画面の日本語を見直しました

- ふつうの開発者向けのソフトの言い回しに合わせて、画面の日本語を書き直しました。
- たとえば、「フォルダ」と「場所」は「ディレクトリ」と「パス」に、「既定」は「デフォルト」に、「索引」は「インデックス」にそろえました。
- ステータスの名前（Active、Paused、Done、Archived）は変えていません。
- ターミナルのコマンド（`hangar`）の出力は、まだ前の言い回しのままです。

## 直したこと

### 右クリックの「Reload」で認証のエラーになっていました

- アプリの中で右クリックすると、WebKit のメニュー（Back と Reload）が出ていました。
  Reload をクリックすると「認証できていません」の画面になり、Back では起動中の画面に戻っていました。
- 入力欄、ターミナル、文字の選択中を除き、このメニューを表示しないようにしました。
  再読み込みは ⌘R か、メニューバーの Reload を使ってください。

### worktree に入ったセッションの目次に、最初のプロンプトが出ていませんでした

- Claude が worktree に入ると、トランスクリプトが別のパスへ移動します。
  このとき、移動先のインデックスまで消して、続きだけを読み込んでいました。
- 移動先は先頭から読み直すようにしました。
  前の版ですでに欠けていたものも、起動時に読み直します。

### Windows で、実行中のセッションを終了と誤ることがありました

- psmux のセッションの一覧から一瞬だけ抜けた実行を、終了として扱っていました。
- 一覧から続けて 2 回抜けたときだけ終了として扱います。
  Claude のプロセスが生きていて、Claude Code にも登録されている間は終了にしません。
- 終了として扱った後に一覧へ戻ってきたときは、実行中に戻します。
  戻したセッションでは、hangar の MCP のツールは使えません。
- 終了と表示しているのに Claude のプロセスが残っている会話を再開しようとすると、「この会話の Claude はまだ終了していません」の確認を表示します。
  2 つの Claude が同じ会話を同時に実行して、トランスクリプトが混ざるのを防ぐためです。
  「停止して再開」か「停止せずに再開」を選べます。

### 長い会話を再開すると「Claude Code との互換性」に誤った記録が残っていました

- Windows で長い会話を再開すると、Claude Code の登録の status が付くまで時間がかかります。
  これをレジストリのずれとして記録し、「アイドル時の自動停止」を無効にしたと表示し続けていました。
- status を待つ時間を 5 秒から 60 秒に延ばしました。
  60 秒を過ぎて記録したものも、あとで status が付けば記録から消します。

### ターミナルで日本語入力の変換中の文字が右端からはみ出していました

- 変換中の文字が長くなったときは、右端で折り返して次の行の左端から表示します。
- 下端を超えるときは上へずらし、ウィンドウの大きさが変わったら位置を合わせ直します。
