# Hangar 0.14.0

エラーや注意の原因調べと、セットアップの残りを、その場からエージェントに頼めるようになりました。

## 足したこと

### エラーや注意から、エージェントに調べてもらえるようになりました

- 起動や同期の失敗、互換性の変更点、ディスクの空き不足などに「エージェントで調査…」を表示します。押すと、内容を入れた新しいセッションのダイアログが開きます。すぐには起動しません。
- エージェントは原因を調べ、この PC の環境の問題なら、承認を得てから直します。hangar の不具合と思われるときは、作者への報告の下書きを作ります。

### セットアップの仕上げを、ボタン 1 つで頼めるようになりました

- ホームの「セットアップの確認」と設定の札に「エージェントで診断…」を表示します。セットアップのすゝめと、いまの準備の状況を入れたダイアログが開きます。
- 足りない道具（git、Codex、opencode）の導入も、承認を得てから任せられます。tmux と claude が無いときは、これまでどおりプロンプトをコピーします。

### 共有のリンクが壊れても、その場で直せるようになりました

- 2 つ目以降のアカウントで、共有のリンクが実ファイルに置き換わったとき、中身が同じなら自動でリンクに戻します。
- 中身が違うときは「修復…」から、ファイルごとに差分を見て、どちらを使うか選べます。選ばなかったほうはバックアップします。

### シェルタブで、iTerm と同じように選んでコピーできるようになりました（macOS）

- 画面より上の履歴も選べます。改行と字下げも崩れません。

## 直したこと

- 公開したアーティファクトのアイコンが、すべて 📄 になっていました。いまは種類に合った線画のアイコンを表示します。
