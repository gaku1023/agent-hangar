# Hangar 0.6.0

## 0.5.0 から上げる人へ（先にお読みください）

### Paused にしたセッションは、自動では止まらなくなります

0.5.0 までは、Paused、Done、Archived を付けたセッションは、Claude がアイドルになってから 10 秒で Hangar が止めていました。
0.6.0 からは、自動で止めるのは Done と Archived だけです。
Paused は戻ってくる会話なので、Claude をそのまま残し、一覧でも実行中として出します。
要らなくなったら、セッション画面か、サイドバーの行のメニューの「停止」で止めてください。

### 「このセッションをどうしますか」と聞かれる回数が減ります

Hangar から起動した Claude は、これまで、頼まれたことを終えたと判断するたびに、この問いを出していました。
0.6.0 からは、明確に終わったときだけ聞きます。
明確に終わったときとは、「ありがとう」「今日はここまで」のように終わりを告げたとき、頼んだことが全部済んで次のステップが残っていないとき、CI やレビューのような外の出来事を待つと伝えたときです。
一手が済んだだけのときや、直しのやりとりの途中では聞きません。
聞かなかったときは、Claude が要約の進捗を書き、待ちが明らかなら状態の提案だけを出します。

Bash と Agent の説明の長さの指示も、「20 字以内」から「短く（20 字程度）」に緩めました。

どちらも、次に起動するセッションから効きます。
いま動いているセッションの指示は変わりません。

### 要約エンジンの既定が「使わない」になります

設定の「要約エンジン」を、使わない、Claude、OpenAI 互換の URL の 3 つから 1 つ選ぶ形にしました。
既定は「使わない」で、0.5.0 から上げた人も「使わない」になります。
LM Studio を使っていた人は、設定で OpenAI 互換の URL を選び直してください（URL とモデルは残っています）。
会話の中で Claude が書く要約は、どれを選んでも今までどおり出ます。

## Claude Code に足すもの

### 設定で、足すものを見て、一部を切れます

設定の「連携」に「hangar が起動する Claude Code に足すもの」を足しました。
足すもの 3 つ（MCP の設定、入力待ちと許可を受け取る hook、システムプロンプトの追記）と、足す指示の全文を読めます。
「区切りで Done／Paused を聞く」と「ターンの意図と操作の短い説明を送る」は、ここのスイッチで切れます。
後者を切ると、右パネルの現在の札には「まだ意図が届いていません」の代わりに、そのターンの依頼の冒頭が出ます。

### 既定のモデルを選べます

同じ場所で、新しいセッションの既定のモデルを選べます。
プロジェクトに前回のモデルがあれば、そちらを先に使います。

## 要約

### 要約エンジンを 1 つの選択にしました

- 使わない：終わった会話の要約を後から作りません。設定の目次に「LM Studio に接続できません」が出続けることもなくなります。セッション画面の先頭のカードは「要約は設定で有効にできます」と言い、「設定」を押すと要約エンジンの設定へ移ります。
- Claude：`claude -p` で作ります。あなたの Claude の使用枠を使います。モデルを選べます（既定は haiku）。
- OpenAI 互換の URL：LM Studio、Ollama、vLLM などの URL に投げます。API キーが要るサーバでは、キーを入れられます。キーは画面に出さず、設定のファイルにだけ置きます。
  JSON スキーマの指定を受けないサーバ（Ollama の古い版など）には、JSON の形を指示文に書いて投げ直します。
  「接続できないときは Claude を使う」は、このときの補助のスイッチとして残しました（既定は切）。

### 会話の中で Claude が書いた要約を残します

会話の中で Claude が書いた要約は、あとから作る要約で上書きしなくなりました。
会話を何ターン続けても、Claude 自身が書いた要約が残ります。
セッション画面から手で作り直したときは、これまでどおり作り直します。

### Claude で作る要約は、その会話のアカウントで走ります

アカウントを 2 つ以上使っているとき、Claude で作る要約は、その会話を動かしたアカウントで走ります。
これまでは、どの会話の要約も最初のアカウントの使用量で走っていました。
週の使用率で要約を控える判定も、その会話のアカウントで見ます。

## プロジェクト

### 登録したフォルダの会話が、その場でプロジェクトに入ります

フォルダをプロジェクトとして登録すると、その下で行った未分類の会話が、その場でそのプロジェクトに入ります。
これまでは、Hangar を起動し直すまで未分類のまま残っていました。
