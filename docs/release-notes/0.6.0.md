# Hangar 0.6.0

## 0.5.0 から上げる人へ（先にお読みください）

### Paused にしたセッションは、自動では止まらなくなります

0.5.0 までは、Paused、Done、Archived を付けたセッションは、Claude がアイドルになってから 10 秒で Hangar が止めていました。
0.6.0 からは、自動で止めるのは Done と Archived だけです。
Paused は戻ってくる会話なので、Claude をそのまま残し、一覧でも実行中として出します。
要らなくなったら、セッション画面か、サイドバーの行のメニューの「停止」で止めてください。

### 「このセッションをどうしますか」と聞かれる回数が減ります

Hangar から起動した Claude は、これまで、頼まれたことを終えたと判断するたびに、この問いを出していました。
0.6.0 からは、明確に終わったときだけ聞きます。
明確に終わったときとは、「ありがとう」「今日はここまで」のように終わりを告げたとき、頼んだことが全部済んで次のステップが残っていないとき、CI やレビューのような外の出来事を待つと伝えたときです。
一手が済んだだけのときや、直しのやりとりの途中では聞きません。
聞かなかったときは、Claude が要約の進捗を書き、待ちが明らかなら状態の提案だけを出します。

Bash と Agent の説明の長さの指示も、「20 字以内」から「短く（20 字程度）」に緩めました。

どちらも、次に起動するセッションから効きます。
いま動いているセッションの指示は変わりません。

## 要約

### 会話の中で Claude が書いた要約を残します

会話の中で Claude が書いた要約は、あとから作る要約で上書きしなくなりました。
会話を何ターン続けても、Claude 自身が書いた要約が残ります。
セッション画面から手で作り直したときは、これまでどおり作り直します。

### Claude で作る要約は、その会話のアカウントで走ります

アカウントを 2 つ以上使っているとき、Claude で作る要約は、その会話を動かしたアカウントで走ります。
これまでは、どの会話の要約も最初のアカウントの使用量で走っていました。
週の使用率で要約を控える判定も、その会話のアカウントで見ます。

## プロジェクト

### 登録したフォルダの会話が、その場でプロジェクトに入ります

フォルダをプロジェクトとして登録すると、その下で行った未分類の会話が、その場でそのプロジェクトに入ります。
これまでは、Hangar を起動し直すまで未分類のまま残っていました。

### プロジェクトの親フォルダは要らなくなり、「新しいフォルダの作成場所（任意）」になりました

これまでの「プロジェクトの親フォルダ」は、始める前に必ず決めるものでした。
0.6.0 からは任意で、役割は「新しいプロジェクト」でフォルダを作る場所と、その直下の自動の登録だけです。
空のままでも使え、新しいフォルダを作るたびに場所を選びます。
すでに親フォルダを決めている人は、見た目も振る舞いも今までと同じです。

### 初日は、Claude Code と会話したフォルダからプロジェクトを選べます

プロジェクトが 1 件も無いときは、ホームのセットアップの確認に「プロジェクト」の行が出ます。
「選ぶ…」を押すと、これまでに Claude Code と会話したフォルダを、git のリポジトリごとにまとめて並べます。
会話の多いフォルダは初めからチェックしてあり、そのまま登録できます。
多くのフォルダが同じ場所にあるときは、その場所を新しいフォルダの作成場所にするかも選べます。
同じ一覧は、設定の「ツール」の「Claude Code と会話したフォルダから登録」からも開けます。

## Paused

### 戻る日を決めずに Paused にできます

Paused にするダイアログの頭に「日付なし」を足しました。
日付なしの Paused は、ホームの「今日」には出ず、一覧の Paused で見られます。
Claude が会話の中で出す Paused の提案も、日付なしにできます。

### 時刻つきの Paused は、その時刻を過ぎてからホームに出ます

これまでは、戻る日が今日なら、時刻の前でも朝からホームの「今日戻る」に出ていました。
0.6.0 からは、時刻を過ぎてから出します。
それまでは、一覧の行に「今日 10:00」のように戻る時刻が出ます。
日付だけの Paused は、今までどおりその日の朝から出ます。
戻る時点を過ぎた Paused は、Claude が休んだまま動いていても、実行中ではなく「今日戻る」に出します。

## 設定

### 自動の Done と自動の停止を、設定で切れます

設定の「一般」に「hangar が自分で行うこと」を足しました。
「止まった会話を自動で Done にする」と「Done と Archived にした会話を停止する」の 2 つのスイッチがあります。
どちらも入りのままなら、これまでと同じです。
自動の停止を切ると、Done か Archived を付けた会話の Claude Code はアイドルのまま残り、一覧でも実行中として出ます。

### 設定の目次の並びが変わりました

一般、ツール、連携、要約エンジン、更新、クラウド同期、情報の順になりました。
クラウド同期は上級者向けのベータなので、後ろへ下げ、目次に「ベータ」と添えました。

### アカウントを画面から足せます

設定の「連携」の「アカウント」で「アカウントを足す…」を押すと、名前と場所を決めるダイアログが開きます。
場所は名前から `~/.claude-<名前>` で埋まり、打ち直すか「選ぶ…」で変えられます。
`~/.claude` と共有するもの（設定、スキル、メモリ、会話の履歴）と、分けるもの（ログインなど）を、登録の前に確かめられます。
選んだ場所に同じ名前の実ファイルがあるときは、上書きせずに残し、その名前を知らせます。
これまでは、名前だけを入れて `~/.claude-2` からの連番の場所に足すか、`POST /api/accounts` に場所を付けて登録する必要がありました。
