# Hangar 0.6.0

## 0.5.0 から上げる人へ（先にお読みください）

### hangar の tmux が専用のサーバに移ります

hangar のセッションは、利用者がふだん使う tmux のサーバではなく、hangar 専用のサーバで動くようになります（Windows の psmux も同じく専用の名前空間です）。

- hangar のセッションは `tmux ls` に出なくなり、`tmux -L hangar ls`（Windows は `psmux -L hangar ls`）で見えます。
- hangar がサーバ全体に入れる設定（クリップボード、Shift+Enter など）は、専用のサーバにだけ入ります。利用者自身の tmux には入りません。
- 利用者の tmux の設定（`~/.tmux.conf`）は、専用のサーバでも読まれます。
- 上げた時点で動いているセッションは、中断にしません。終わるまで、これまでの tmux のサーバで動かし続け、hangar の画面からも外のターミナルからも開けます。新しく起動するセッションから、専用のサーバに入ります。
- シェル連携（`claude.zsh`）は、上げたあとに開いたターミナルから専用のサーバへつなぎます。上げる前から開いているターミナルで `claude` を打つと、セッションは起動しますが、そのターミナルからはつながりません。hangar から開くか、ターミナルを開き直してください。
- これまでの tmux の中（利用者自身の tmux のセッションを含む）で `claude` を打つと、専用のサーバへ入れ子でつなぎます。
