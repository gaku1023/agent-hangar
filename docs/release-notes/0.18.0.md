# Hangar 0.18.0

予定で、新しい会話のモデル、effort、アカウント、権限などを選べるようになりました。エージェントからの通知は、返答を書き終えてから届くようになりました。

## 足したこと

### 予定で、新しい会話の起動の設定を選べるようになりました

- 新しいセッションの画面と同じ項目（プロジェクト、アカウント、モデル、effort、権限モード、worktree、追加ディレクトリ、名前）を選べます。プロジェクトは検索でき、クイックセッションや新しいディレクトリも選べます。Codex と opencode では、それぞれの項目を選べます。
- 繰り返す予定で worktree を指定すると、実行の回ごとに、予定時刻を含む名前で新しく作ります。
- 予定に設定したアカウントが削除されていると、その回の実行は失敗になり、実行の履歴に理由が表示されます。

### エージェントも、予定と新しい会話で同じ項目を指定できるようになりました

- MCP から予定を作成・変更するときに、起動の項目を指定できます。新しい会話の作成では、Codex のアカウントと opencode の自動承認も指定できます。

## 直したこと

- エージェントからの Windows とスマホの通知が、返答を書き終える前に届いていました。いまは、会話が返答を終えて入力待ちになってから届きます。
