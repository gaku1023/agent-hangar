# Hangar 0.16.0

作業中の画面を軽くしました。エージェントが開始した会話は、起動元の会話の下にまとめて表示されます。

## 更新の前に

データベースの版が上がるため、更新したあとは前の版に戻せなくなります。

## 足したこと

### エージェントが開始した会話を、起動元の下にまとめて表示するようになりました

- サイドバーと一覧で、起動元の下に線でつないで並べます。矢印で折りたためます。折りたたむと、中の会話の状態を丸で並べて表示します。
- 会話の画面には、起動元へのリンクと、開始した会話の札を表示します。
- まとめて表示されるのは、その会話を実行した PC の中だけです。

### LM Studio のサーバーが停止していても、そのまま会話を開始できるようになりました

- 会話を開始するときに、LM Studio のサーバーが停止していれば自動で起動します。

## 直したこと

- 処理中の会話を開いている間、GPU と CPU を使い続けていました。端末の枠と処理中の丸のアニメーションをなくし、色だけで状態を表すようにしました。
- 複数の PC で同期していると、サーバーが 30 秒ごとに約 1 秒止まり、画面の表示が途切れることがありました。この PC に反映できないデータの再試行を省くようにしました。該当のデータは、これまでどおりこの PC には同期されません。
- Done と Paused の会話からも、未読の数や通知が届いていました。届かないようにし、Paused の会話はサイドバーにも表示しないようにしました。
- サイドバーの項目が増減するときに、動きを付けました。
