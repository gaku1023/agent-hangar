# Hangar 0.10.2

新しい会話のダイアログからアーカイブしたプロジェクトを検索できるようになり、opencode への指示で会話を Done にできるようになりました。

## 足したこと

### アーカイブしたプロジェクトを検索できるようになりました

- 新しい会話のダイアログでプロジェクトを検索すると、アーカイブしたプロジェクトも検索結果の末尾に「Archived」と表示されます。
- アーカイブしたプロジェクトで新しく会話を始めると、そのプロジェクトは自動的に Active に戻ります。

## 直したこと

- opencode に「この会話を Done にして」と指示しても、会話の状態が変わらない問題を直しました。今は指示するとその場で Done や Paused に変わります。また、作業の区切りで opencode が状態の変更を提案するようになりました。
