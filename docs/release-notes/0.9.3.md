# Hangar 0.9.3

サイドバーの「実行中」をプロジェクトごとに分け、画面の補助の文を減らし、Dock のバッジと Claude Code の新しい版への対応を直しました。

## 足したこと

### サイドバーの「実行中」がプロジェクトごとに分かれました

- 実行中の会話を、プロジェクトの見出しの下にまとめて出します。見出しを押すと畳めます。畳んだプロジェクトに入力待ちがあると印が出ます。
- 8 件を超えると「ほか N 件」にまとめていましたが、今は全部を出し、多いときは行の部分だけがスクロールします。
- 見出しをドラッグするか ⌥↑↓ で、プロジェクトごと並べ替えられます。

### 見出しの下の説明を ⓘ にしまい、画面をすっきりさせました

- 設定やダイアログの説明は、見出しの横の ⓘ を押すと読めます。注意、許可の案内、取り消せない操作の結果は、これまでどおり画面に出します。
- 一覧の行の状態は札だけで示し、実行中は札の中の丸が動きます。ホームの「実行中」の行は、名前と作業の中身と時刻だけにしました。

## 直したこと

- macOS で、入力待ちの数が Dock のアイコンのバッジに出ていませんでした。今は通知の許可を求めるときにバッジも求めるので、バッジが出ます。すでに通知を許可している場合は、設定の「通知」をいったんオフにしてオンに戻すと、システム設定の Hangar の通知に「バッジを表示」の項目が出ます。
- Claude Code 2.1.308〜2.1.310 で増えたファイルを、設定の互換性の表が「形式のずれ」として出していました。今はこれらをアカウントごとのファイルとして扱い、ずれとして出しません。確かめた Claude Code の版は 2.1.310 になりました。
