# Hangar 0.7.3

リリースノートを、アプリの中で読めるようにしました。

## 足したこと

### 設定の「更新」で、版ごとのリリースノートを読めます

- 版ごとの行を押すと、要点だけが開きます。全部を読むときは「全文を読む」を押します。
- 上げる前に注意が要る版には「更新の前に」の札が付きます。
- 読んでいる間は、その版の行が一覧の上に残ります。「すべて閉じる」でまとめて畳めます。

### 更新したあと、変わったことを一度だけ知らせます

- 新しい版で初めて開いたとき、右下に「更新しました」の札を出し、要点を 3 つまで載せます。
- 版を飛ばして上げたときは、間の版の分もまとめます。

### 「更新あり」の札に、次の版の要点が出ます

- 入れる前に、何が変わるかが分かります。
- ほかの PC や Worker とそろえる注意がある版は、その注意を黄色い地で先頭に出します。
- この札に要点が出るのは、0.7.3 から次の版へ上げるときからです。
