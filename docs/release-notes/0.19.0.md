# Hangar 0.19.0

別の PC で hangar のセッションを起動し、その結果を元の会話で受け取れるようになりました。

## 更新の前に

別の PC への起動を使うには、使う PC をすべて 0.19.0 に上げ、Worker を更新してください。更新しなくても、PC の同期とスマホはこれまでどおり動きます。

1. 使う PC をすべて 0.19.0 に上げます。
2. クラウドを作成した PC で、リポジトリを clone したディレクトリから `npm run hangar -- setup cloud` を実行します。データやリカバリーキーはそのままで、同じクラウドの Worker だけが更新されます。

- 0.19.0 で開くと、手元のデータベースが新しい形式に上がります。0.18.x に戻すことはできません。

## 足したこと

### 新しいセッションの画面で、起動する PC を選べるようになりました

- 見出しの右の札で PC を選びます。その PC にディレクトリが無いプロジェクトや、使えないアカウントは、選ぶ前から薄く表示されます。
- 別の PC で起動したセッションは、起動元のセッションの下に、PC 名の札つきで並びます。

### エージェントが別の PC でセッションを起動し、その結果を受け取れるようになりました

- MCP の `create_session` に `device` を指定すると、その PC で起動します。起動した会話のターンが終わるたびに、最後の返答と要約が、元の会話への入力として届きます。
- 起動した会話が Done になったときと、閉じられたときにも、それぞれ 1 回ずつ知らせが届きます。
- 起動したセッションには、`send_to_session` で続きを頼めます。
- PC の一覧は、MCP の `list_devices` で調べられます。

### 別のプロジェクトやクイックセッションでの起動は、承認してから始まります

- エージェントが、元の会話とは違うプロジェクトやクイックセッションで起動しようとすると、PC とスマホに承認の札が出ます。承認するまで起動しません。
- 起動の依頼と結果は、PC どうしの鍵で暗号化したうえで、クラウドを経由します。
