# Hangar 0.9.1

スマホに通知を出せるようにし、0.9.0 への再構築で参加できなかった場合を直しました。

## 更新の前に

- スマホの通知を使うには、Worker の更新が要ります。クラウドを作成した PC で、リポジトリを clone したディレクトリから `npm run hangar -- setup cloud` を実行してください。同じクラウドのまま Worker だけを更新し、データやリカバリーキーはそのままです。
- 0.9.0 からの更新では、再構築は要りません。まだ 0.8.x の PC は、0.9.0 の「更新の前に」の手順で再構築してください。

## 足したこと

### スマホに、入力待ちの通知を出せます

- スマホの hangar の受信箱で「通知を受け取る」を押すと、PC の会話が入力待ちや許可待ちになったときに通知が出ます。
- 23:00〜7:00 は鳴らしません。
- iPhone と iPad では、ホーム画面に追加した hangar で使えます。
- 通知の中身（会話の題と PC の名前）は、スマホ用の暗号鍵で暗号化してから送ります。Cloudflare からは読めません。
- 通知を押すと、その会話の行を開きます。

## 直したこと

- 0.8.x の古い設定に Worker の名前が入っている PC は、古いクラウドを別の PC で削除した後でも、新しいクラウドに参加できませんでした。古いクラウドがもう無いことを確かめたうえで、古い設定をバックアップしてから参加できるようにしました。
- `hangar cloud teardown` の最後の案内を、0.9.0 の手順（他の PC は 0.9.0 に更新してから、参加コードで上書きして参加）に合わせました。
