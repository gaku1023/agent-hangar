# Hangar 0.7.2

0.7.1（クラウド同期の作りを変えた版）に上げるときの不具合を 2 つ直しました。
0.7.0 から上げる場合の手順は [0.7.1 の更新の前に](https://github.com/gaku1023/agent-hangar/releases/tag/v0.7.1) を読んでください。この版から上げるときも同じです。

## 直したこと

- クラウドを作った PC で `hangar setup cloud` をやり直すと、その PC の同期が「unauthorized」で止まり、Hangar を開き直すまで戻りませんでした。
  setup cloud はこの PC を参加し直させ、端末の鍵を新しくします。動いている Hangar は古い鍵のまま送り続けていました。
  いまは、断られたときに新しい鍵を読み直して、そのまま同期を続けます。
- 同期の版が合わない古い Worker に、止まる前に 1 回だけ未送信の変更を送っていました。
  いまは、書き込む前に Worker の版を確かめ、合わなければ何も送らずに止まります。
