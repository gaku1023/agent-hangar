# Hangar 0.4.0

## 0.3.0 から上げる人へ（先にお読みください）

### データベースが版 21 に上がります

初めて起動したときに、Hangar のデータベースが版 21 に上がります。
上げたあとは、前の版のアプリには戻せません。
上げる前の控えは、自動で `~/.agent-hangar/backups/db/` に取られます（名前は `hangar-v20-<時刻>.db`）。

### セッションのノートを廃止しました

セッションに 1 行のノートを書く機能を外しました。
ほとんど使われておらず、要約と、Paused の戻る日と理由が、同じ役を担っているためです。

- セッション画面の見出しの「ノート」の札と、終わったセッションの冒頭の 1 枚にあったノートの欄を外しました。
- 一覧の行のノートの印と、一覧で m を押すと開いたノートの入力欄を外しました。
- セッションの名前は、これまでどおり残ります。

中身の入っていたノートは、上げたときにデータベースから消えます。
画面にも、MCP の応答にも出なくなります。
上げる前の控え（`~/.agent-hangar/backups/db/hangar-v20-<時刻>.db`）には残っています。
残したいノートがあるときは、上げる前に要約や `CLAUDE.md` などへ写してください。
上げたあとでも、控えから次のように取り出せます。

```bash
sqlite3 ~/.agent-hangar/backups/db/hangar-v20-<時刻>.db "select session_id, memo from session_notes where memo is not null"
```

覚えておきたいことは、これからは次の場所に書いてください。

- セッションの中身と次にやることは、要約（Claude が `set_session_summary` で書き、画面の「要約を再生成」でも作れます）。
- いったん止めて戻ってくるものは、Paused にして、戻る日と理由を付けます。
- プロジェクト全体に関わることは、`CLAUDE.md` などの指示のファイルに書きます。

### MCP の `set_session_memo` を外しました

道具の一覧から `set_session_memo` を外しました。
上げる前から動いている Claude が呼んだときは、何も書かれずに、道具が無いというエラーが返ります。
`list_sessions` の結果と、`get_project` の直近のセッションからも、`memo` の項目を外しました。

### 同期している PC が 0.3.0 のままでも、同期は止まりません

0.3.0 の PC と 0.4.0 の PC が混ざっても、同期はそのまま続きます。

- 0.3.0 の PC で書いたノートは、0.4.0 の PC には届かず、受け取った側で捨てられます。
- 0.4.0 の PC が名前を書き換えても、0.3.0 の PC の手元にあるノートは消えません。

0.3.0 の PC のノートを残したいときは、その PC を上げる前に写してください。
