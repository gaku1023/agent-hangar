# Hangar 0.4.0

## 0.3.0 から上げる人へ（先にお読みください）

### データベースが版 21 に上がります

初めて起動したときに、Hangar のデータベースが版 21 に上がります。
上げたあとは、前の版のアプリには戻せません。
上げる前の控えは、自動で `~/.agent-hangar/backups/db/` に取られます（名前は `hangar-v20-<時刻>.db`）。

### セッションのノートを廃止しました

セッションに 1 行のノートを書く機能を外しました。
ほとんど使われておらず、要約と、Paused の戻る日と理由が、同じ役を担っているためです。

- セッション画面の見出しの「ノート」の札と、終わったセッションの冒頭の 1 枚にあったノートの欄を外しました。
- 一覧の行のノートの印と、一覧で m を押すと開いたノートの入力欄を外しました。
- セッションの名前は、これまでどおり残ります。

中身の入っていたノートは、上げたときにデータベースから消えます。
画面にも、MCP の応答にも出なくなります。
上げる前の控え（`~/.agent-hangar/backups/db/hangar-v20-<時刻>.db`）には残っています。
残したいノートがあるときは、上げる前に要約や `CLAUDE.md` などへ写してください。
上げたあとでも、控えから次のように取り出せます。

```bash
sqlite3 ~/.agent-hangar/backups/db/hangar-v20-<時刻>.db "select session_id, memo from session_notes where memo is not null"
```

覚えておきたいことは、これからは次の場所に書いてください。

- セッションの中身と次にやることは、要約（Claude が `set_session_summary` で書き、画面の「要約を再生成」でも作れます）。
- いったん止めて戻ってくるものは、Paused にして、戻る日と理由を付けます。
- プロジェクト全体に関わることは、`CLAUDE.md` などの指示のファイルに書きます。

### MCP の `set_session_memo` を外しました

道具の一覧から `set_session_memo` を外しました。
上げる前から動いている Claude が呼んだときは、何も書かれずに、道具が無いというエラーが返ります。
`list_sessions` の結果と、`get_project` の直近のセッションからも、`memo` の項目を外しました。

### 同期している PC が 0.3.0 のままでも、同期は止まりません

0.3.0 の PC と 0.4.0 の PC が混ざっても、同期はそのまま続きます。

- 0.3.0 の PC で書いたノートは、0.4.0 の PC には届かず、受け取った側で捨てられます。
- 0.4.0 の PC が名前を書き換えても、0.3.0 の PC の手元にあるノートは消えません。

0.3.0 の PC のノートを残したいときは、その PC を上げる前に写してください。

## アプリの中で、クラウド同期に参加し、PC を管理できるようになりました

これまでは、ほかの PC をクラウド同期に参加させるのに、ターミナルで `hangar join` を打つ必要がありました。
また、参加させた PC を同期から外す手段がありませんでした。

- 設定 › クラウド同期 で参加トークンを貼ると、宛先のホストを確かめてから参加できます。参加トークンは画面にも記録にも残りません。
- 参加している PC が、参加日、最終同期、最後に同期した IP、おおよその場所つきで並びます。場所は Cloudflare の推定で、市区町村はよく外れます。
- 手放した PC やなくした PC は「解除…」で同期から外せます。解除した PC は一覧に残ります。
- 解除だけでは、参加トークンを持っている PC は参加し直せます。締め出したいときは、クラウドを作った PC で参加用の秘密を作り直してください。
- 「この PC の参加を解除」で、この PC だけ同期をやめられます。クラウドのトランスクリプトは消しません。
- ほかの PC から解除された PC には、その旨と、参加し直す道が出ます。
- ターミナルでは `hangar cloud devices`、`hangar cloud revoke <ID>`、`hangar cloud leave` が使えます。

**Worker の入れ替えが要ります。** クラウドを作った PC で `hangar setup cloud` をもう一度実行してください。
入れ替えるまでは、PC の一覧に「Worker の更新が要る」と出ます。同期そのものは続きます。

## MCP、ステータスライン、シェル連携をボタンで入れられるようになりました

- 設定の「連携」の節で、MCP サーバーの登録、ステータスラインの設定、シェル連携のインストールと、それぞれの解除をボタンで行えます。ホームの「始める前の確認」の行にも、同じボタンが出ます。
- 書く前に「書き込みの確認」の窓が開き、書く先のファイル、新規か変更か削除か、差分、同じことをするコマンドを見せます。「書き込み」を押したときだけ書き、書く前にバックアップを取ります。
- 確認の窓を見せた後に別のプログラムがファイルを変えていたら、何も書かずに止まります。
- 他の PC から届いた設定の適用と、バックアップに戻す操作も、同じ窓で確認します。
- ブラウザで開いた画面からは書き込まず、ターミナルで打つコマンドを出します。
- `hangar statusline uninstall` を足しました。`hangar mcp`、`hangar shell`、`hangar statusline` に、書かずに差分だけを見る `--dry-run` を足しました。
- `hangar mcp uninstall` は `claude mcp remove` を呼ばず、Hangar が `~/.claude.json` を直接書きます（書く前にバックアップを取ります）。
- Windows では、ステータスラインのスクリプトが PowerShell（.ps1）のとき、PowerShell の行を入れます。シェル連携は、引き続き Windows では使えません。

## 「いま」の札が中身に合わせて縮むようになりました

セッション画面の右の列の「いま」の札は、これまで一度伸びると縮まず、短い中身の下に空白が残っていました。
これからは中身に合わせて伸び縮みします。
縮むのは、状態（作業中、入力待ちなど）が替わったときと、問いやサブエージェントの 1 行が出入りしたときだけです。ツール呼び出しのたびには縮まないので、下の目次が細かく跳ねることはありません。
