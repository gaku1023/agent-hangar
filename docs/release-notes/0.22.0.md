# Hangar 0.22.0

すべての会話を見渡して許可や質問に答える「統括」と、スマホで会話を開いて続ける画面を足しました。

## 更新の前に

0.22.0 を一度起動すると、データベースの形が変わり、前の版には戻せなくなります。

これまでの版の PC や Worker との間でも、同期はそのまま動きます。Worker の更新は任意です。効き目は下の「スマホで会話を続けるには」にあります。

## 足したこと

### 統括の会話が、あなたに代わってほかの会話の許可や質問に答えます

- 統括は既定で切です。設定の「統括」の節で入りにすると、常駐の会話が 1 つ起動します。エージェントは Claude Code・Codex・opencode から選び、アカウント・モデル・effort も決められます。
- サイドバーの「統括」の行か ⌘⇧J（Windows は Ctrl+Alt+J）で、右に統括の会話を出す柱が開きます。統括に許可の方針を言葉で伝えると、統括はその範囲でほかの会話の許可や質問に答えます。
- 柱の右上の丸から、新しい会話・停止・再開を選べます。会話が長くなると、手が空いたときに自動で新しい会話へ切り替わります。

### 統括と声で話せます

- 柱のマイクを押して話しかけると、統括が声で答えます。
- Mac ではマイクの代わりに丸いボタンが出ます。押している間だけ声を拾うことも、一度押して拾い続けることもできます。読み上げの声は、同梱の声、OS の声、別に入れた VOICEVOX・AivisSpeech から選べます。

### スマホで会話を開いて続けられます

- スマホで入力待ちの札や通知を押すと、その会話の画面が開きます。続きを読んで文を送れるほか、許可や質問に答えることも、作業を中断することもできます。いまは Claude Code の会話だけです。
- 設定に「スマホ」の節を足しました。接続用の QR コード、つないだスマホの一覧、「スマホからの送信を受ける」のスイッチがあります。
- スマホから会話を起動する画面で、worktree と名前を決められます。許可の確認を飛ばす Bypass での起動も選べます。

### ほかの PC で動いている会話がサイドバーに出ます

- 作業中か入力待ちかと、待っている時間を、この PC の会話と同じ形で出します。要らなければ、設定の「一般」の節で出さないようにできます。
- ほかの PC の会話はメニューから停止できます。
- ほかの PC の会話へ送った文は、その会話が作業中でも「中断して渡す」ですぐに渡せます。

### 設定の同期を種類ごとに、切・確認・自動から選べます

- 指示・スキル・記憶・設定などの種類ごとに、同期しない「切」、確かめてから入れる「確認」、自動で入れる「自動」から選べます。権限に関わる設定は、自動にしても確認を求めます。
- 自動で入れたものは履歴に残り、1 項目ずつ戻せます。MEMORY.md の競合は、両方の行を残して自動で解消します。

### 会話の続きから新しい会話を始められます

- 「同じ設定で新しいセッション…」のダイアログで「この会話の続きから」を選ぶと、元の会話の流れを引き継いだ新しい会話を始められます。メニューの「フォーク」は無くし、このダイアログにまとめました。

## 変わったこと

- `claude -p` のように人とやり取りせずに走る会話は、会話の一覧・未読・サイドバーに出しません。プロジェクトごとの一覧の末尾に畳んでまとめ、検索ではこれまでどおり見つかります。
- ほかの PC や統括が Claude Code の会話の許可や質問に答えるとき、画面にキーを打つのでなく、Claude Code へ答えを直に渡します。画面から札を読み取れないときも答えられます。
- 返答を終えた会話では、エージェントが続けて呼んだツールを「ツール呼び出し N 回」の 1 行にまとめます。
- エージェントが知らせ（notify_user）を出さないまま返答を終えたときは、hangar が未読を 1 つ付けます。
- エージェントが hangar の設定を読んで変えられるようになりました。言語と通知の出し方はそのまま変え、ほかの項目は変える前にあなたに確かめます。道具の置き場所や鍵などは変えられません。
- GitHub などのできごとで会話を動かす「イベント」は、既定で切です。使うときは、設定の「クラウド」の節で入りにします。すでにイベントの設定を承認してある PC は入りのままです。

## 外したこと

- プロジェクトの「以前のノート」の画面、要約に使う OpenAI 互換の接続先、ほかの PC へ SSH でつなぐ予備の経路を外しました。ほかの PC とはクラウドを通してつながります。

## 直したこと

- 時計が進んでいる PC の変更を取り込むと、その後にこの PC で書いた変更が同期で捨てられることがありました。いまは後から書いた方が残ります。
- 設定の同期の競合でこの PC の値を採っても、相手の PC が前の値のままでした。いまは相手もその値にそろいます。
- 2 文字の検索で本文の最後の 2 文字が見つかりませんでした。
- hangar を再起動すると、まだ出していなかった通知と未読の数が消えていました。
- Markdown で、表の中の改行、エスケープした記号、`***`、画像が正しく描かれませんでした。
- Windows で起動に時間がかかると、サーバがまだ立ち上がる途中なのに失敗の札が出ていました。
- 解除した PC が起動先の一覧に残っていました。
- ほかの PC の会話で、前に答えた札と同じ文面の札が出ると、10 分のあいだ答えを断られることがありました。

## スマホで会話を続けるには

Worker を更新すると、スマホで会話を開いて続けられるようになり、ほかの PC で会話が始まったり終わったりしたことも、数秒でサイドバーに届きます。更新しなくても、同期、スマホからの会話の起動、ほかの PC の会話とのやり取りは、これまでどおり動きます。

1. スマホから開きたい会話がある PC を 0.22.0 に上げます。
2. クラウドを作成した PC で、リポジトリを clone したディレクトリから `npm run hangar -- setup cloud` を実行します。データやリカバリーキーはそのままで、同じクラウドの Worker だけが更新されます。
