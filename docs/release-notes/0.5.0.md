# Hangar 0.5.0

## 0.4.0 から上げる人へ（先にお読みください）

### データベースが版 23 に上がります

初めて起動したときに、Hangar のデータベースが版 21 から版 23 に上がります。
上げたあとは、前の版のアプリには戻せません。
上げる前の控えは、自動で `~/.agent-hangar/backups/db/` に取られます（名前は `hangar-v21-<時刻>.db`）。

足す表は、どれもこの PC の中だけで使うもので、同期しません。

- 版 22 は、途中で終わったセッションの再開と、同じファイルの編集の警告に使う表を足します。
- 版 23 は、使用制限で止まっているセッションを覚える表を足します。

### クラウドの Worker の入れ替えは要りません

同期で運ぶものは変わっていません。
0.4.0 の PC と 0.5.0 の PC が混ざっても、同期はそのまま続きます。

### 「VS Code で開く」が、選んだエディタの名前になります

0.4.0 までの設定の「code のパス」は、上げたときに「VS Code（そのパス）」の選択として読み替えます。
これまでどおり VS Code で開き、ボタンの文言だけが「<名前> で開く」に変わります。

### パレットの語が変わります

パレットの「入力待ち」の群は「要対応」に、「次の入力待ちへ」は「次の要対応へ」になりました。
許可待ちと、使用制限のリセット済みも、この群に入るためです。

## 止まっている理由が見えるようになりました

- Claude がツールの許可を求めて止まると、赤い盾と「許可待ち」で知らせ、何の許可か（道具と命令）を出します。道具と命令は、hangar から起動したセッションで届きます。
- 使用制限で止まったセッションは、砂時計とリセットの時刻で出します。ヘッダーの「停止 N」から一覧を開けます。
- 自動で続かないままリセットを過ぎたものは、「リセット済み」として要対応に上がります。
- Paused や Done にしたセッションでも、使用制限でリセットを待っている間は自動で止めません。Claude Code の自動の続きが消えないようにするためです。
- 一覧の欄で `is:permission` と `is:limited` が使えます。

### 通知

- 窓が別のアプリの裏にあって画面が止まっていても、入力待ちの通知が届くようにしました。
- 許可待ちの通知は、問いの文を待たずにすぐ出します。
- 使用制限に当たったときに、アカウントごとに 1 通知らせます。

## 再起動のあとに、途中だったセッションをまとめて再開できます

PC を再起動したり tmux が止まったりして途中で終わったセッションは、ホームの「前回実行中」に並びます。
止まる前に作業中だったものから順に並び、「すべて再開」で同時に 2 本ずつ再開します。
Paused、Done、Archived を付けたセッションは並びません。
一覧の行と、セッションの冒頭の 1 枚には「中断」の印が付きます。
再開は会話を開き直すだけで、途中だった作業は自動では続けません。

## 同じファイルを 2 本のセッションが編集していると知らせます

実行中の 2 本が同じファイルを交互に編集しているとき、ホームの実行中の行、セッション画面の現在の札、サイドバーに琥珀の印が出ます。
止めることはせず、通知も出しません。
印を押すと、相手とファイルの一覧と、worktree で新しいセッションを始めるボタンが開きます。
Bash で書き換えた分は拾えません。

## エディタを選べるようになりました

「VS Code で開く」が、選んだエディタの「<名前> で開く」になりました。
設定の「一般」の「エディタ」で、この PC で見つけた VS Code、Cursor、Windsurf、Zed、IntelliJ IDEA、WebStorm から選べます。
一覧に無いエディタは「任意のコマンド」に書けます。
エディタが見つからないときは、その場でほかのエディタで開くか、設定で選び直せます。

## git のブランチと未コミットの件数が見えるようになりました

一覧、ホームの実行中、セッション画面、プロジェクト画面に、作業中のブランチと未コミットの件数が出ます。
セッションが変えたファイルの差分も、Hangar の中で読めます。
Hangar は git には書きません。

フォルダの持ち主が今のユーザーと違うために git が読むのを断ったときは、セッションの (i) とプロジェクト画面でそう伝え、許すためのコマンド（`git config --global --add safe.directory <場所>`）を出します。
git の設定は Hangar では変えません。

セットアップの確認に、git とエディタの行が入りました。
git が無いときは入れ方のコマンドを出します（無くても使えます）。

## 小さな直し

- プロジェクト画面で右パネルを閉じても、開くボタンが同じ場所に残るようにしました。
- 起動に失敗したときの画面で、更新の知らせが後から出ても、画面が上へずれないようにしました。
- 「指示とメモリ」で、ファイル名が途中で切れないようにしました。
- 目次がいちばん下にあるときは、「最新へ移動」を出さないようにしました。
- この PC に場所の無いプロジェクトでは、エディタで開くボタンと「ターミナルで開く」を押せないようにしました。開けなかったときの知らせは、しばらくすると消えます。画面を開いただけで「プロジェクトが見つかりません」のエラーが出ることも、「ブランチと worktree」が「取得中…」のまま止まることもありません。
- Windows で、答えた入力待ちの通知が通知センターから外れないことがあったのを直しました。
- macOS を再起動したあと、終わっているはずのセッションが「実行中」のまま残ることがあったのを直しました。
