# Hangar 0.16.1

端末に出力が多いときと、設定を同期しているときの動作を軽くしました。

## 足したこと

### エージェントが開始した会話を、起動元から切り離せるようになりました

- サイドバーの会話を右クリックして「起動元から切り離す」を選ぶと、起動元の下から外れて独立した会話になります。元には戻せません。
- 起動元を Done か Archived にすると、その下にまとめていた会話は、独立して表示されます。起動元の状態を戻すと、また起動元の下にまとまります。

## 直したこと

- 端末に出力が続けて流れている間、画面の描画で CPU を多く使っていました。出力をまとめて描くようにし、負荷を減らしました。キー入力の表示は遅れません。
- 設定の同期をオンにしていると、サーバーが 1 分ごとに一瞬止まっていました。変わっていない設定ファイルは読み直さないようにしました。
- サイドバーで、ほかの会話を下にまとめていない会話にカーソルを乗せても、状態の丸が消えていました。いまは、折りたためる会話だけが、丸を開閉の矢印に替えます。
