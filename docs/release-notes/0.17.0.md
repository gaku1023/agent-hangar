# Hangar 0.17.0

指定した時刻に会話を自動で実行する「予定」と、サイドバーのピン留めを追加しました。エージェントが会話を削除するときは、画面での承認が必要になりました。

## 更新の前に

データベースの版が上がるため、更新したあとは前の版に戻せなくなります。

## 足したこと

### 指定した時刻に、会話を自動で実行できるようになりました

- サイドバーの「予定」から作成します。1 回だけ、曜日と時刻、N 分おきから選び、新しい会話を開始するか、既存の会話にメッセージを送ります。
- 予定は作成した PC でだけ実行されます。PC が閉じていた間の回は、次に起動したときに最新の 1 回だけ実行します。
- エージェントも MCP から予定を作成・変更できます。

### エージェントによる会話の削除に、画面での承認が必要になりました

- エージェントが会話の削除を求めると、画面の上部に確認が表示されます。「ゴミ箱へ移動」を押すまで削除されません。
- スマホの受信箱からも承認できます。

### サイドバーで、会話のピン留めと「未読に戻す」ができるようになりました

- 右クリックのメニューから操作します。ピン留めした会話は一覧の上部に固定され、ほかの PC にも同期されます。
- 「同じ設定で新しいセッション…」を選ぶと、同じプロジェクトとモデルが設定された新規作成の画面が開きます。

### リマインダーの「今すぐ試す」から、Paused の会話をすぐに再開できるようになりました

- 押すと、会話を再開して Paused にした理由を渡し、その会話を開きます。

### エージェントやスクリプトから、会話の終了を待てるようになりました

- MCP の `wait_for_session` と、コマンドの `hangar run` を追加しました。`hangar run` は結果を返し、終了コードで成否を判別できます。

## スマホから削除を承認するには

スマホの受信箱に承認を表示するには、Worker の更新が必要です。clone した場所で `setup cloud` をもう一度実行してください。更新しなくても、PC の画面からは承認できます。

## 直したこと

- 別の ID で届いた会話が、手元の会話と重複して表示されることがありました。同じ会話として扱うようにしました。
- Windows で会話が多いと、サーバーが一瞬止まることがありました。端末の一覧の読み込み方を変えました。
- ほかの PC で終了した会話が、実行中と表示され続けることがありました。
- opencode の会話を再開するとき、最後に使ったモデルの接続先を先に準備するようにしました。
- エージェントが新しい会話を開始するとき、準備に時間がかかっても待たずに応答を返すようにしました。
- 5 時間の枠がないアカウントで、5 時間の使用量が表示されていました。
