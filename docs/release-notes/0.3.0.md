# Hangar 0.3.0

## 0.2.0 から上げる人へ（先にお読みください）

0.2.0 から、更新の札の「ダウンロードしてインストール」で上げられます。
署名は 0.2.0 と同じなので、警告も許可の取り直しも出ません。

### データベースが版 20 に上がります

初めて起動したときに、Hangar のデータベースが版 20 に上がります。
上げたあとは、前の版のアプリには戻せません。
上げる前の控えは、自動で取られます。

### 同期している PC は、なるべく同じ時期に上げてください

TODO に「Claude の提案」の区別が増えたため、古い版の PC は、この区別を知りません。
上げるまでの間、古い版の PC では、Claude の提案が確定の TODO に見えます。
上げ終わるまでは、古い PC で提案を済みにしないでください。

### 止まったセッションが、自動で Done になります

上げたあとの最初の起動で、状態の無い Active のセッションのうち、次のどちらかに当たるものが Done になります。

- Hangar の外で起こした、3 ターン以下のもの（`claude -p` や、外のターミナルの短い問いなど）。
- 要約の進捗が、完了か中止のもの。

Done になったセッションも、resume して発言すれば、今までどおり状態が外れます。
Active は、続きがあるものだけが残る一覧になります。

### プロジェクトのノートは、「指示とメモリ」の欄に替わります

プロジェクト画面のノートは廃止して、「指示とメモリ」の欄に替わります。
前のノートの中身は消えません。
中身があるときは「以前のノート」として読めるので、コピーするか、`CLAUDE.md` などへ移してから消してください。

MCP の `update_project` の `append_memo` は、何も書かずに案内を返すようになりました。
同じ呼び出しのほかの項目は、これまでどおり書かれます。
指示は `CLAUDE.md` などの指示のファイルに書いてください。

## 新しくなったこと

### TODO

- プロジェクト画面の TODO を、一般的な TODO アプリのように作り直しました。
  - 長い文は折り返して全文を出します。
  - ダブルクリックか Enter で、その場で直せます。Enter で確定、Esc で取り消し、空にすると消えます。
  - つまみのドラッグか ⌥↑ と ⌥↓ で並べ替えます（⌥⌘ で先頭と末尾）。
  - 済みにすると、チェックが埋まって取り消し線が引かれ、少し置いてから、畳んだ「Done」の節へ入ります。
  - 消すときに確認は出ません。その場の「取り消し」の帯が 6 秒出ます。
  - ⌘Z で、TODO の変更を戻せます。
  - ↑↓ と j k で選び、Space と x で済み、Enter で編集、⌫ で削除、a で追加します。ショートカットの一覧に「TODO」の群を足しました。
  - 末尾の「TODO を追加」の行から、続けて何件でも足せます。
- Claude が足す TODO は、承認制になりました。
  - `update_project` の `add_todos` は、確定の TODO でなく、提案を作ります。
  - 提案は「Claude の提案」の節に並び、受け入れると末尾に入り、却下すると消えます。2 件以上のときは「すべて受け入れる」も出ます。
  - 提案は、未完了の件数にも、新しいセッションへ渡す TODO にも入りません。
  - Claude が済みの提案を出す `propose_done` は、完了の確認の小さな札（「Done?」）で出ます。押すと、理由とセッションが開き、承認と却下を選べます。
- プロジェクト一覧の「いま」の列に、受け入れていない提案があるプロジェクトの「提案 N」を出します。画面を開かなくても気づけます。

### プロジェクト画面

- 右の欄のノートを、「指示とメモリ」の欄に替えました。
  Claude Code が起動時に読むファイルを、読むだけで見せます。
  - 出すのは、あるものだけです。`CLAUDE.md`、`.claude/CLAUDE.md`、`CLAUDE.local.md`、`AGENTS.md`、いまのアカウントの自動メモリ（`MEMORY.md`）です。
  - 行ごとに、名前、大きさ、更新、種類（プロジェクト指示、ローカル指示、自動メモリ）を出します。
  - 行を押すと、Markdown を整えて読めて、開いている間も読み直します。
  - 行の印と、画面のボタンから、エディタで開けます。
  - `CLAUDE.md` の種類のファイルが作業フォルダかその上にあるときは、`AGENTS.md` に取り消し線を引いて「読まれません」と出します。
  - Hangar が、これらのファイルを作ったり書いたりすることはありません。
  - 全体の様子は、セッションで `/context` を打つと見られます。
- 画面を窓の高さに収めました。
  右の欄の中身が増えても、ページ全体は伸びません。左の一覧と右の欄は、それぞれでスクロールします。
  - 右の欄の節（TODO、指示とメモリ、アーティファクト）は、見出しを押すと畳めます。畳んだ形は、プロジェクトごとに覚えます。
  - スクロールしている間も、いま見ている節の見出しが上に留まります。
  - アーティファクトは 3 件まで出し、残りは末尾の「すべて表示」で広げます。
- 起こすセッションへ渡す指示から、ノートの行を外しました。MCP の `get_project` からも、`memo` の項目を外しました。

### セッション画面

- 「いま」の帯を、目次の上の札（いまの札）へ移しました。
  帯はタブの下にあり、選んでいるタブに付いて見えていました。
  札は右の欄にあり、タブにもターミナルにもつきません。
  - 状態、Claude の問い、意図の全文、最近の道具の呼び出し 3 件を縦に並べ、続きは「ほか」、サブエージェント、成果物の札で見られます。
  - 表記を「ステップ N、経過時間」にしました（ターンの始まりから数えます）。
  - 文脈の使用量と費用は、見出しの (i) の詳細へ移しました。
  - 右の欄を畳むと、札も目次と一緒に畳まれ、ターミナルが窓の幅まで広がります。
  - 新しい道具の呼び出しは、すっと現れて一度光ります。意図と問いは、替わるときに重なって切り替わります。動きを減らす設定では、これらを止めます。
- 札の高さは、増える方にだけ動きます。意図の折り返しや道具の数で、下の目次が上下に跳ねなくなりました。
- 止まったセッションの会話は、最新の発言（いちばん下）から開きます。検索の結果から開いたときは、その発言へ跳びます。

### ヘッダー

- 「移動・操作」のバーが、画面によって左右にずれなくなりました。
  広い窓では、セッション画面とほかの画面で、バーの位置が違っていました。
- バーの大きさを、窓の幅で 3 段に変えます。
  狭い窓では虫眼鏡だけ、中くらいでは今までの形、広い窓では「セッションと操作を検索」と書いた長い欄（最大 600px）になります。

### セッションの状態

- 止まった Active のセッションは、条件に当たれば、自動で Done になります（上の「止まったセッションが、自動で Done になります」を参照）。
  - 判定は 15 秒ごとに見回り、60 秒続けて当たったものだけを書きます。
  - ほかの端末のセッション、Claude の登録にあるもの、生きたセッションがあるもの、Paused の提案があるもの、却下したもの、要約を待っているもの、「Active に戻す」のあとに動きが無いものは、対象外です。
  - Hangar の外で起こした 4 ターン以上のセッションは、止まったときに事後の要約を回します（このサーバが起きてから止まったものだけです）。
- Done と Archived にしたセッションが問いで待っていても、入力待ちには数えません。
  プロジェクト一覧の「入力待ち」の数、パレットの群、一覧の行の語、サイドバーの印、ホームの実行中の札、検索の `is:waiting` が、ホームの要対応と同じ数になります。
  サイドバーには行を残し、点は休みと同じ色で出します。

### ターミナル

- セッション画面のターミナルで ⌘C を押したときに、macOS の警告音が鳴らなくなりました。
  Claude Code の画面や tmux のコピーモードは、ドラッグを離した時点で自分でコピーを済ませます。
  そのあとに ⌘C を押すと、写すものが無いので音が鳴っていました。
- 空のコピーは行いません。
  Option を押しながら選んだ範囲は、これまでどおり ⌘C で写ります。

## 前提

- macOS 13 以降の Apple silicon、または Windows 11 の x64。
- Node 22、tmux（Windows は psmux）、Claude Code（`claude`）。アプリは Node を同梱していません。
