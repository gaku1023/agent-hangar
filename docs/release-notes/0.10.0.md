# Hangar 0.10.0

Claude Code に加えて、opencode の会話を Hangar で始めて、見て、続けられるようにしました（ベータ）。

## 更新の前に

0.10.0 で開くと、手元のデータベースが新しい形に上がり、0.9.x に戻せなくなります。同期しているほかの PC は、0.9.x のままでも同期できます。

## 足したこと

### opencode の会話を Hangar で扱えます（ベータ）

- 設定 › 連携 › opencode で「opencode を有効にする」を入れると使えます。デフォルトはオフで、オフのままなら今までと何も変わりません。
- opencode は別に入れておきます。設定に、入っている版と、Hangar で確かめた版を出します。
- macOS と Windows で使えます。Windows では、opencode を npm ではなく、`opencode.exe` の形で入れてください。
- 設定から、opencode で使うプロバイダーを追加できます。API キーかブラウザでのログインでつなぎ、OpenAI 互換のサーバーも追加できます。
- macOS では「opencode コマンドを hangar 経由で起動」を入れると、ターミナルで打った `opencode` も Hangar の会話として始まります。

### 新しい会話で、エージェントに opencode を選べます

- モード（build・plan）、モデル、自動承認を選んで起動します。
- モデルの一覧には、無料のモデルと、学習に使われないかどうかの印を出します。

### opencode の会話も、Claude と同じ画面で追えます

- 一覧、サイドバー、タブにエージェントのアイコンが付きます。
- 「いま」の札、許可待ち、使用量の帯と費用を出し、本文は検索できます。
- 閉じた会話は「再開」で同じ会話に戻れます。
- Hangar を終了すると、opencode の会話も止まります（Claude の会話は続きます）。もう一度開いたら「再開」で続けられます。

### ほかの PC やスマホからも opencode の会話を扱えます

- ほかの PC の opencode の会話を読み、「ここで再開」で引き継げます。
- スマホの一覧に opencode の会話が出て、スマホから opencode の会話を始められます。

## スマホの新しい画面を使うには

スマホで opencode の会話を見たり始めたりするには、クラウドを作成した PC で Worker を入れ替えます（`hangar setup cloud` をもう一度実行）。入れ替えなくても、PC 同士の同期は今までどおり動きます。

## 直したこと

- Windows で、いくつかの端末が同時に閉じると、Hangar のサーバが落ちて「サーバーに接続できません」になることがありました。端末をつなぐ部品を、この不具合を直した版に上げました。
- Windows で、端末を開いて閉じるのを繰り返すと Hangar のサーバのメモリが増え続け、長く使うと落ちることがありました。今は閉じた端末のメモリを解放します。
- 配布版の `hangar` コマンドが標準入力を読めず、`hangar cloud join` や `hangar recover` が「標準入力が対話型ではない」で止まっていました。今は入力を受け付けます。
- ほかの PC で動いている会話の見出しに、「実行中」と「終了」が並んで出ることがありました。今は動いている間は「終了」を出しません。
- 解除した PC の名前が、PC の一覧で消えていました。今は解除した後も名前を出します。
- 検索の結果で、一致した語が本文の頭に近いと抜き出しが語の途中で切れ、強調が付かないことがありました。今は語が丸ごと入るように抜き出します。
