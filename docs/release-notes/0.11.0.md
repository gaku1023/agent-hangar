# Hangar 0.11.0

会話を画面に並べて開けるようになり、Codex をベータとして使えるようになりました。Codex は、設定の「連携」で有効にするまで、Codex に関する表示が何も出ません。

## 更新の前に

0.11.0 を起動すると、この PC のデータベースが新しい形式に更新され、0.10.2 以前には戻せなくなります。同期しているほかの PC は、0.10.2 のままでも同期できます。

## 足したこと

### 会話を並べて開けます

- サイドバーの会話をドラッグして本体へドロップすると、画面を左右や上下に分けて、会話を並べて開けます。ドロップする前に、分かれる位置のプレビューが出ます。
- 各ペインの見出しをドラッグすると、ペインを入れ替えたり、別の位置へ動かしたりできます。
- すでにペインに開いている会話を開こうとすると、新しく開かず、そのペインへ移り、札で知らせます。
- 右クリックの「右に分割して開く」「下に分割して開く」や、キー（macOS は ⌘D・⌘⇧D、ほかの OS は Ctrl+Alt+D など）でも分けられます。
- 境目の角をつかむと、縦と横の大きさを同時に変えられます。分割中の ⌘W はシェルのタブを閉じ、閉じるタブが無ければペインを分割から外します。

### Codex の会話を Hangar から始められます（ベータ）

- 設定 › 連携 › Codex で「Codex を有効にする」をオンにすると、新しい会話のダイアログで Codex を選べます。モデル、推論、権限を選べます。権限は「読み取りのみ」「自動」「フルアクセス」の 3 段で、既定は「自動」です。
- フルアクセスは確認なしでコマンドを実行するため、選ぶと札が赤くなり、注意が出ます。
- 使うには codex（検証済みは 0.164.x）が PATH にあり、ログイン済みである必要があります。未確認のバージョンでは知らせの札が出ます。

### 一覧と検索に Codex の会話が出ます

- Hangar の外で始めた Codex の会話も、一覧と検索に出ます。題名の左に Codex のアイコンが付きます。
- 状態（実行中、入力待ち、許可待ち）と、許可や質問の内容を表示します。Hangar 上からは答えられないので、許可や質問には起動元のターミナルで答えてください。
- 会話の再開と fork ができます。最初の発言の前に終わった会話は、再開できません。
- 終わった会話では「Codex を終了しました」と表示し、「再開」から続きを開けます。

### ヘッダの使用量が、開いている会話に合わせて切り替わります

- Codex の会話を開くと、ヘッダの 5 時間・週の枠が ChatGPT のプランの枠になります。Claude の会話では、これまでどおり Claude の枠です。
- Codex の会話では、右の欄の「いま」の札の下に、コンテキストの使用量とモデルを表示します。

### ターミナルの codex を Hangar 経由で起動できます

- 設定で「codex コマンドを Hangar 経由で起動」をオンにすると、外のターミナルで実行した codex が Hangar の会話として開きます。macOS と Linux のみです。
- exec や login などのサブコマンドと、`command codex` は、そのまま codex を実行します。

### そのほか

- MCP の create_session で、opencode を指定して会話を始められます。
- `hangar project add` で追加したディレクトリが、ほかの PC の同じプロジェクトに結び付くようになりました。

## 制限と未確認のこと

- Codex の対応はベータです。Windows では動作を確かめていません。「codex コマンドを Hangar 経由で起動」は macOS と Linux のみです。
- Codex の会話は、ほかの PC への同期とスマホにはまだ出ません。次の版で対応します。
