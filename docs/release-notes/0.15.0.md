# Hangar 0.15.0

エージェントが、終わったことや判断が要ることを知らせてくれるようになりました。知らせ方は、言葉で伝えて決められます。

## 更新の前に

データベースの版が上がるため、更新したあとは前の版に戻せなくなります。

## 足したこと

### エージェントからの知らせが、未読の数としてたまるようになりました

- エージェントは返答を終えるたびに、何が起きたかを 1 文で知らせます。サイドバーの会話の一覧に未読の件数を表示し、その会話を開くと既読になります。
- ホームには「未読」の札を表示し、知らせの 1 行をまとめて読めます。macOS では Dock のバッジにも、入力待ちと合わせた件数を表示します。

### 知らせ方を、言葉で伝えて決められるようになりました

- 最初の会話の終わりに、エージェントが知らせ方を尋ねます。「終わったときだけスマホに」のように答えると、その内容が設定として保存されます。
- 「未読の数」「Mac や Windows の通知」「スマホの通知」のそれぞれに、終わったとき・判断が必要なとき・途中の報告のどれで知らせるかを割り振れます。
- 今の設定は、設定の「一般」の「知らせ方」で確認できます。変えるときは［エージェントで変える…］を押します。

## 直したこと

- デスクトップ版で、会話の画面のリンク（返答の中のリンクや PR の札など）を押しても何も起きませんでした。ブラウザで開くようにしました。
- macOS で、初めての通知のときに出る確認で「許可」を選んでも、その通知が表示されませんでした。許可したその通知から表示するようにしました。
