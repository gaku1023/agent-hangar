# Hangar 0.9.5

クラウド同期で、同じ Artifact が 2 台で別々に記録されたときの食い違いを直しました。

## 更新の前に

この版はデータベースの形を新しくします。更新した後は、前の版に戻せません。

## 直したこと

- 同じ Artifact を 2 台が別々に記録すると、片方の PC で取り込めないまま残り、同期のログに「親の行が無いので当てられなかった行」が出続けていました。いまは、先に記録された方に 1 つにまとめ、更新の履歴も重複させずにそろえます。
- 更新した PC では、それまで取り込めずに残っていた分も、次の同期で片付きます。もう 1 台の PC を同じ版にそろえなくても直ります。
