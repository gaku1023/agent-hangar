# Hangar 0.9.2

スマホに設定の画面を足し、スマホの受信箱の表示と、他の PC の会話の再開の案内を直しました。

## 更新の前に

- スマホの新しい画面と直しを使うには、Worker の更新が要ります。クラウドを作成した PC で、リポジトリを clone したディレクトリから `npm run hangar -- setup cloud` を実行してください。同じクラウドのまま Worker だけを更新し、データやリカバリーキーはそのままです。
- Worker を更新したら、スマホのホーム画面の hangar を一度閉じて開き直してください。

## 足したこと

### スマホに設定の画面ができました

- 受信箱の右上の歯車から開きます。「通知」「新しい会話のデフォルト」「接続」の 3 つがあります。
- 「通知を受け取る」は、受信箱から設定の「通知」に移りました。

### 通知を鳴らさない時間帯を変えられます

- 設定の「通知」で、「夜は鳴らさない」をオフにするか、開始と終了の時刻を変えられます。
- デフォルトは今までと同じ 23:00〜7:00 です。設定はスマホごとに効きます。

### 新しい会話のデフォルトを決めておけます

- PC、アカウント、権限、モデル、effort を決めておくと、新しい会話の画面を開いたときに最初から選ばれています。

### スマホから自分の接続を解除できます

- 設定の「接続」で、このスマホの接続を解除できます。QR を読んで接続し直すこともできます。
- 解除したスマホは、PC の設定のスマホの一覧からも消えます。

## 直したこと

- スマホの受信箱で、PC の名前の代わりに長い ID が出て、画面が横にずれることがありました。今は PC の名前を出し、長い名前は省略して横にずれないようにしました。
- 他の PC で始めた会話について、Claude が `claude -r` での再開を案内していましたが、この PC にはトランスクリプトが無いため再開できませんでした。今は Hangar の「この PC で再開」を使うよう案内します。
