# Hangar 0.12.0

Codex と opencode の設定、共通のスキル、フックなどを PC 間で同期できるようになり、Codex の会話も他の PC で続けられるようになりました。

## 更新の前に

同期している PC は、すべて 0.12.0 にそろえてください。この版でデータベースの版が上がるため、前の版には戻せません。

## 足したこと

### Codex・opencode・共通の設定を同期できるようになりました

- Codex、opencode、共通のスキル、フックとステータスライン、プラグイン、MCP、Hangar の設定を、設定の同期の対象にできます。
- どれも既定では無効です。設定の「設定を同期」で、対象ごとに有効にします。
- Claude の settings.json の `permissions.*` のキーは、他の PC から初めて受信するときに、承認が必要になりました。

### Codex の会話を PC 間で同期できるようになりました

- Codex の会話の本文が PC 間で同期され、他の PC で再開、引き継ぎ、削除ができます。

### スマホから Codex の会話を始められるようになりました

- スマホから Codex の会話を始められ、一覧にも表示されます。

### Git などで管理されているディレクトリを見分けるようになりました

- 設定のディレクトリが Git などで管理されているときは、それを見分けて表示します。
