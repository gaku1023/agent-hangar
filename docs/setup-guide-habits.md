# 最初の 1 週間で試すこと

全部覚えなくてかまいません。場面が来たら、1 つずつ試してみてください。
Claude に読ませたときは、Claude が 1 つ選び、その場で一緒に試します。

- **ちょっと試したいだけのとき**
  ⌘⇧N（Windows は Ctrl+Shift+N）でスクラッチを始めると、フォルダを決めずに始められます。育ったら、セッションの「プロジェクトに昇格」でフォルダごと移せます。
- **今日はここまでのとき**
  ターンの終わりに「このセッションをどうしますか」と聞かれたら Paused を選び、戻る日と時刻を付けると、その時刻にホームの札と通知で知らせます。
- **同じリポジトリで 2 本動かすとき**
  2 本が同じファイルを交互に編集すると、琥珀の印が出ます。押すと、worktree で新しいセッションを始めるボタンが出ます。
- **前にやったことを探すとき**
  ⌘K で検索するか、Claude に「前に〇〇をやったセッションを探して」と頼むと、hangar の検索で見つけます。
- **ターミナルから claude を起動したいとき**
  シェル連携（macOS）を入れていれば、ふだんどおり `claude` と打っても hangar に載ります。
