ページ分けを入れると、2 と 3 を同じ部品にそろえられます（検索はサーバの offset と limit がそのまま使える。上限は 1 回 200 件）。

スクショの画面です。いまは Done を 3 件だけ見せて「ほか N 件」でタブへ移っています。

3. Done の札をどこに置くか

いまの札は右端の時刻の左にあり、時刻の文字幅（「4 時間前」と「15 時間前」）で左右にずれ、名前から遠い（広い窓では 1,000px 以上離れる）。Done の節の中では見出しが Done と言っているので、同じことを 3 回言っている。下は同じ 6 行（Done・Done・Paused・提案あり・Archived・実行中）を各案で描いたもの。

画面の幅 広い幅で、札と名前の離れ方を見比べられます（横にはみ出したら横スクロール）

軸を変えた案です。右端の縁にそろえる（D8・D9）、名前の頭にそろえる（D10・D11）、2 段目の見立てとまとめる（D12）、文字を使わず行で言う（D13・D15）、左に語の列を作る（D14）。

3f. Fable との壁打ちから出た 7 案

Fable の見立て（P1〜P4 が「もう一歩」な理由）
  1. 「何か」の列に「いつ」を入れた。Done・Archived は状態、「10/5（日）」は日付。混ぜると列の意味がぼやけ、幅も日付に引っ張られて 84〜128px に育つ。欲しいのは「Paused を札に」であって「日付を左に」ではない。
  2. 1,223 件の Done が緑の壁紙になる。全体の 97% に最も強い色を与えている。目で拾いたいのは残り 3%（印なし・Paused・Active・提案）。
  3. 止まった行で、灰の点と札が二重に「止まっている」と言う。2 段目の「済んだ」とも重なる。
  4. 提案（紫）が右端に残り、「この行をどうするか」を読むのに画面を往復する。
  5. 名前の書き出しが右へ押される。「Done を左に」は「名前の近くに」の言い換えで、「名前の前に」ではなかったかもしれない。
共通の手として、戻る日は右端の時刻の列へ移す（Paused の行の時刻は「戻る日」を黄土で出す。今日・過ぎは塗る）。状態の列には語だけを置く。
