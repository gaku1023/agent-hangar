# セッション一覧のページ送りと状態の列

2026-10-02。試作は `2026-10-02-session-paging/paging.html`。

## 利用者の要望

- 表示されるセッションの数を、1 ページ目・2 ページ目のように区切り、表示数も選べるようにしたい。
- Done の札の位置が気に入らない。調べると、時刻の文字幅で札が左右にずれる、広い窓で名前から遠い、Done の節の中で見出しと重なる、の 3 つだった。
- 途中で「Home など、セッションが一覧で出るページ全部に適用して。見せ方は任せる」と追加された。

## 決定

### ページ送り（A4 と S1）

- 一覧の下に帯を貼る。左に「1–50 / 1,223 件」、中ほどに「‹ 1 2 3 … 25 ›」、右に「ページ [ ] / 25」と「50 件ずつ」。
- 1 ページの件数は 25・50・100・200。既定は 50。どの一覧も同じ件数を使い、端末の localStorage（`sessions.pageSize`）に残す。
- 件数を変えたら、見ていたページの先頭の行を含むページに留まる。
- 全件が 25 件以下なら帯を出さない。
- セッション画面は、条件もタブも無い節の読み方では今のまま（Done は 3 件と「ほか N 件 ▸」でタブへ移る）。タブ・条件・検索の平らな一覧にだけ帯を出す。検索はサーバの offset と limit でそのページだけを読み、「さらに読み込む」はやめた。条件を変えるか画面に入り直すと 1 ページ目に戻る。
- Home の最近は 30 件で切るのをやめ、全件をページで送る（見せ方は任されたので決めた）。
- プロジェクト画面は、Done の「ほか N 件」や Archived の「表示」で広げた節の行だけをページに分ける。上の節（今日戻る・動いている・続き）と見出しは毎ページ出す。節を広げる・畳むと 1 ページ目に戻る。

### 状態の列（F1。Fable との壁打ちで出た案）

- 行を `点 16px ｜ 状態 62px ｜ 本文 ｜ 右端（動き・⋯・時刻 72px）` にする。
- 状態の列には語だけの同じ幅の札を置く。Done は線だけ（全体の 97% なので静かにする）、Paused は黄土の地、Archived は灰の地。状態の無い行は Claude の提案の札（Done？・Paused？、ポインタで言い切り）を置く。
- 戻る日は時刻の列へ移す（先の日は黄土の文字、今日・過ぎた日・日付なしは塗り）。最後の活動はポインタで読める。2 段目の頭は Paused の行も要約の見立てに戻る。
- 状態がどれも同じタブ（Done・Paused・Archived・印なし）では列を畳む。
- 行の部品は共通なので、セッション画面・プロジェクト画面・Home の最近のどれにも効く。

### 試作で退けたもの

- ページ送りの置き場所 A1〜A3、節の中で送る S2、一覧全体を区切る S3。
- 札の位置 D1〜D15、右側で幅をそろえる W1〜W6、左の列 L1〜L5、左の列に戻る日も入れる P1〜P4（「何か」の列に「いつ」が混ざり、列が 84〜128px に育った）。

## 残り

- Home の最近は半分の幅の欄なので、狭い窓（900px）では状態の列のぶん名前の省略が増える。
