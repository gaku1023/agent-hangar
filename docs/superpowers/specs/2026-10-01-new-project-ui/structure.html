構成 P5：起動では場所を選ぶ／プロジェクト画面では作る

起動ダイアログでは、プロジェクトに加えて「新しいフォルダ」と「未登録のフォルダ」も始める場所として選べ、起動と同時にプロジェクトになります（作る手順を別に踏みません）。プロジェクト画面には作成のダイアログを置きます。サーバの「フォルダを作る＋git init＋登録」は昇格と共通にします。上の札か ← → で切り替えてください。

1. 起動ダイアログ：新しいフォルダで始める

一覧の中身はいまと同じで、下端に「作る」操作を 2 つ固定します。検索の語がどのプロジェクトにも未登録のフォルダにも一致しなければ、下端の 1 行目が「『url』を新しいフォルダとして作る」に変わり、Enter で選べます。選ぶと、プロジェクト欄の下に名前（検索の語を引き継ぐ）と git init が出て、見出しが「新しいフォルダで始める」に変わります。ボタンは「起動」のままで、押すとフォルダを作り、登録して、起動します。

2. 起動ダイアログ：既存のフォルダで始める

未登録のフォルダは、打った語に一致したときだけ「未登録」の札付きで混ざります（何も打たない一覧には出しません。昔の課題のフォルダを 67 行眺めることはしません）。選んで起動すると、そのフォルダをプロジェクトに登録します。ワークスペースの外は「ほかの場所を選ぶ…」から macOS のダイアログで選びます。

3. プロジェクト画面：作成のダイアログ

見出しの右に「＋ 新しいプロジェクト」を置きます。作成のダイアログは「新しいフォルダを作る／既存のフォルダを登録」の切り替えで、下端は「作成」（プロジェクトの画面へ移る）と「作成して始める」（作ったら新しいセッションのダイアログを、そのプロジェクトを選んだ状態で開く）。既存のフォルダは、ワークスペースの未登録を名前で探せる一覧、Finder、パスの入力の 3 つから選べます。

4. 対案：起動からも同じ作成ダイアログを開く

比べるための対案です。起動ダイアログの下端の「新しいプロジェクト…」から ⑧⑨ と同じダイアログを重ね、作ったら起動ダイアログへ戻って、そのプロジェクトが選ばれています。部品は 1 つで済みますが、起動の途中で 1 枚寄り道します。
