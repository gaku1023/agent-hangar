ここで決めるのは、設定の画面の構成（3 案）、同期の節の見せ方、言語の切り替えの置き場、Claude Code の設定の同期の 5 つの一覧の形（それぞれ 2 案）です。

推す案：S1　節を左の目次で切り替える。次点：S2　1 枚の一覧に畳む

S1節を左の目次で切り替えるmacOS のシステム設定の形。左の目次の 1 行に今の状態を添え、右は選んだ節だけ。クラウド同期は 1 頁に状態、操作、PC、Claude Code の設定、使用量がそろう推す
S21 枚の一覧に畳む設定の全部を 1 行ずつの要約（名前と今の値）にし、押した行だけがその場で開く。言語や通知のような小さい設定は行の中で切り替える次点
S3操作と状況に分ける上のタブで「設定」（変えるもの）と「状況」（読むもの）を分け、設定は札の格子で 1 画面に収める。同期の使用量は状況の側へ

設定の同期の 5 つの一覧は、下の「設定の同期の流れ」で (a)〜(e) ごとに 2 案ずつ並べました。推すのは a1、b1、c2、d1、e2 です。

読み方

  • 上の切り替えで案を選ぶと、その案の画面を 1280×800 の窓で描きます。構成の案は「開いた直後」と「同期の節」の 2 枚で、同期している人と同期していない人を例のデータの切り替えで替えられます。
  • 言語の切り替え（日本語、English）は構成の 3 案の窓に効きます。切り替えた直後にどう見えるかを、そのまま確かめられます。ステータスの札は英語のままです。設定の同期の流れの窓は日本語だけです。
  • 「設定の同期の流れ」の (a)〜(e) は 2 案を横に並べます。件数は 8 項目と 60 項目で切り替えられ、ネイティブの確認ダイアログは macOS のダイアログに似せた絵で示します。
  • 各案の下に、利用者の 5 つの動き (1)〜(5) で何回の操作でどこを通るかの表と、得るもの、失うもの、作り替えの重さを置きました。操作の回数は「たどり着くまで」で、打鍵は 1 回、ダイアログで決めて押すのも 1 回です。
  • いまの設定の画面は 5 つの群（必須、連携、要約器、同期、情報）に 16 の節と約 40 の項目が 1 枚に縦に並び、読み物（使用量の表、索引、この PC、互換の見張り）が項目の 3 分の 1 ほどを占めています。

推す案と理由

構成は S1（節を左の目次で切り替える）を推します。 初めて入れた人が設定でまずすることは、言語を確かめ、連携の要修正を潰し、気が向いたらクラウド同期を始めることです。 S1 は左の目次が「クラウド同期　同期オフ」「連携　要修正 2」のように今の状態を 1 行ずつ添えるので、開いた直後に何がどうなっているかが読め、押せば右がその節だけになります。 クラウド同期は 1 頁に状態、操作、PC、Claude Code の設定の同期、Cloudflare の使用量と月の予算がそろい、論点 2 の「1 つの節で見せる」に素直です。 いまの作り（1 枚に目次、スクロールで群を追う）から、目次を頁の切り替えに変えるだけなので、段 4 の 1 本の PR に収まります。 操作の回数は S2 と S3 に 1 回ずつ負けますが、その 1 回は「どの節か」を目次で選ぶ分で、迷いは増えません。

次点は S2（1 枚の一覧に畳む）です。 設定の全部が 1 行ずつの要約で 1 画面に収まり、言語と通知は行の中で切り替えられるので、動き (3) と (4) が最短です。 ただし、クラウド同期のように大きい節を一覧の途中で開くと、下の行が画面の外へ押し出され、要約エンジンやツールのように欄の多い節は折りたたみの中で窮屈になります。 いまの作りからは遠く（目次の仕組みと群の見出しを捨てる）、作り替えは S1 より重いです。 S1 の目次の「今の状態の 1 行」は、S2 のこの長所を取り入れたものです。

S3（操作と状況に分ける）は推しません。 設定が 1 画面の札の格子に収まる軽さは魅力で、動き (1)、(2)、(4) は最短です。 しかし Cloudflare の使用量と無料枠での停止が「状況」のタブへ移り、「同期を一時停止する」と「なぜ止まったか」が別の場所になります。 同期を使わない大半の人には「状況」のタブが使用量と索引とこの PC だけの薄い画面になり、タブの意味が伝わりません。 1 つ目の試作で「読み物は設定のまま」と決めた以上、設定の中でさらに分けるより、S1 の「情報」の節に集める方が覚えることが少なくて済みます。

同期の節（論点 2）。 同期を使っていない人には、1 文の説明と「クラウドを用意して始める」「参加トークンで参加」の 2 つのボタンだけを見せ、PC の一覧も使用量も出しません。 Claude Code の設定の同期は、押せないスイッチと「クラウド同期を始めると使えます」の 1 行で、ある事だけ知らせます。 同期している人には、状態の 1 行（同期済み、最終受信、未送信の変更、未送信のトランスクリプト）、3 つのボタン（今すぐ同期、同期を一時停止、参加トークンを表示）、PC の一覧、Claude Code の設定の同期の 5 行、Cloudflare の使用量と料金（札 3 つと棒 3 本、停止のしきい値の目盛り）、月の予算（D4、Paid のときだけ効く）の順に並べます。 無料枠で止まったときは、状態の札が「無料枠で停止」になり、使用量の上に理由と「UTC 0:00 にリセット」の帯が出ます。

言語の切り替え（論点 4）。 置き場は設定の「一般」の先頭（S1）、一覧の先頭の行（S2）、「一般」の札の先頭（S3）で、3 案とも設定を開いて最初に目に入る位置です。 値は「日本語」と「English」の 2 つの切り替えで、押した瞬間に画面の全部（サイドバー、ヘッダー、設定の見出しと説明）が切り替わり、保存のボタンも再起動も要りません。 ステータスの札（Active、Paused、Done、Archived）と公式の語（Claude Code、MCP、LM Studio）は両方で同じ表記です。 上の切り替えで English を押すと、この試作の窓でその直後の見え方を確かめられます。

設定の同期の一覧（論点 3）。 推すのは a1（種類ごとの折りたたみ）、b1（操作ごとの折りたたみで、競合と削除を上に）、c2（表にチェックで、印の無いものをまとめて承諾）、d1（差分を最初から出す）、e2（同期の節に常設の行と、送った直後の通知カード）です。 理由は下の表にまとめました。 いずれも 60 項目で読めることを、上の「件数」の切り替えで確かめられます。

緑の升はその動きでいちばん少ない案です。回数は「たどり着くまで」です。(5) は、2 台目でスイッチを入れると適用の一覧がすぐ開く前提で数えています。
