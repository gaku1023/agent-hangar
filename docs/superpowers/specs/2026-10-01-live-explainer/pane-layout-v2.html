右ペイン 第 2 版：Fable と 2 回壁打ちして絞った 3 構成と、部品の比較

壁打ちで変わった前提：「いま〜している」は左のターミナルの最終行の言い換えで、横目ならターミナルが速い。右ペインはターミナルに映らないものに使う。ここまでの累積、何のためか、なぜ止まったか、どの層を触っているか、そして指揮役の日に映らないサブエージェントの中身。

材料の実測：大きい 3 本の transcript で Bash が 6〜7 割、指揮役のセッションは Agent 300・SendMessage 129。Bash は 923 件すべてに Claude が書いた 1 行の説明（description）があり、1 手ごとなので古くならない。そこで「何をしているか」はコマンド辞書ではなく description を主にし、注入で「description は日本語・20 字以内」と頼む（無ければ英語のまま出す）。Read / Edit / Write はパスから決まった文にする。

読む書く走らせる失敗サブエージェント「引用符」 隣に確かめる事実が無い自己申告（ターンの意図）だけ
