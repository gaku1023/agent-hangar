Cloudflare の正確な数と今月の費用は、読み取り専用のトークンを入れると出ます。
npm run hangar -- setup cloud --usage-token
・トークンが無くても同期はいつもどおり動き、見張りも今の見積もりで続ける。
・トークンは Worker の secret に置き、Worker が Cloudflare に問い合わせて全部の PC に配る（PC ごとに入れる必要は無い）。
・問い合わせは数分ごとにまとめる。今日の数は GraphQL（数分遅れ）、費用は 1 日 1 回の更新。
