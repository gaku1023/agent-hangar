hdesign.md の決まりの書き換え

「見た目と動き」の節を、次のように書き換えます。

許す新しく許すもの

  • ガラス（浮く部品だけ）
  • グラデーション（主ボタンと背景の光だけ）
  • 影（浮く部品と、持ち上げた板だけ）
  • 脈動（端末の縁の「作業中」だけ）

禁じる引き続き禁じるもの

  • 読む面へのガラス
  • シマー、スケルトン、タイピング風の表示
  • 文字の影、光る文字
  • ダークモード

変える参照先

  • Linear → macOS 26 の Liquid Glass
  • アイコンは Lucide 16px、線幅 1.5 のまま

守る試験で固定するもの

  • 本文の色は白地で 4.5:1 以上
  • ステータスの文字は淡い地で 4.5:1 以上
  • ぼかしは決めた部品のクラスにだけ現れる
  • reduced motion で動きの長さが 0、光も止まる
