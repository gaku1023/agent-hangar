サイドバーの文字の大きさ

ナビの文字は今 --fs-md（15px）で、中身の本文（13px）やパンくず（13px）より 2px 大きい。英語の Home / Projects のときは Inter の小文字が低いので釣り合っていたが、日本語にすると字面が四角く詰まって、同じ 15px でもひと回り大きく見える。文字の大きさ、太さ、アイコンと行の高さ、字間の 4 つの軸で案を並べた。どれも実物の寸法で描いている。押すと枠が付く。

1. 文字の大きさだけを変える

アイコン 20px、行 38px、太さ 560 はそのままにして、文字だけを下げる。

2. 文字と一緒に、アイコンと行も詰める

文字だけ小さくすると、20px のアイコンと 38px の行が勝って見えることがある。閉じた帯のアイコンも同じ大きさに揃える前提。

3. 太さと字間で整える

日本語は太さ 560 だと黒く固まりやすい。選択中の太さを落とすか、字間を少し空けて軽くする。

4. 自分で調整

つまみを動かすと右の値が変わる。気に入った値をそのまま伝えてもらえれば入れる。
