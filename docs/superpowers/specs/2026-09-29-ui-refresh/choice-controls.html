いま hangar で選択肢を出している部品の多くは、ブラウザ標準の <select> と <input type=checkbox> のままです。開いた一覧は macOS の素のメニューになり、ガラスと光の見た目から浮いています。節ごとに、比べられるよう現状（灰色の地）と案を並べました。どれも実際に触れます。キーボード（↑ ↓ Enter Esc）も効きます。
