動き ②：このアプリならではの「決めの動き」

性格は B（なめらか）で統一しています。ロゴの「掛かった札」と、端末の「縁の灯」から生まれる 6 つの動きです。それぞれの「▶」で再生できます。入れたいものをいくつでも選んでください。多すぎると賑やかになるので、絞る目安は 3〜4 個です。

1　起動

Hangar
サーバを起こしています…

竿が引かれ、端末の札が手前から奥へ掛かって揺れ、止まると名前が浮かぶ。ロゴそのものが読み込み中の表示になる。

使う所：.app の起動画面、初回の索引中

2　新しい札が掛かる

新規セッションを起こすと、新しい札が竿に掛かって揺れ、先に掛かっていた札は横へ詰める。ロゴと同じ仕草。

使う所：Home の実行中の札、新規セッション

3　待ちが降りてくる

エージェントが入力を待つと、通知が上から糸で吊られて降りてきて、軽く揺れて止まる。その場で答えられる。

使う所：入力待ちの通知（いまの右下のトーストを置き換え）

4　縁の灯が一周する

› keys.ts の表を見直して
● Read packages/ui/src/keys.ts
● Edit keys.ts +24
● Bash npx vitest run keys

状態が変わった瞬間だけ、新しい色の光が端末の縁をひと回り走ってから落ち着く。変わったことに気付ける。常には動かない。

使う所：セッション画面の端末（作業中 ⇄ 入力待ち ⇄ 休み）

5　行が画面へ広がる

一覧の行を開くと、その行がそのままセッション画面へ広がる（名前と状態の点が同じ場所から動く）。どこから来たかを見失わない。戻ると縮んで行へ帰る。

使う所：一覧 → セッション、Home の札 → セッション

6　終わった札が奥へ霞む

「同期の床を刻む」が終わりました — 最近へ

セッションが終わると、その札が竿の奥へ滑りながら霞んで消え、最近の一覧へ移る。ロゴの「奥ほど霞む」と同じ意味。

使う所：Home の実行中の札
