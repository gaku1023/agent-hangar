何を決めるための試作か

終了済みのセッションの本文（と、実行中の目次で開いたターンの中身）の描き方を決めます。今は Claude の返答の Markdown が素の文字のまま（表の縦線、- 、[名前](URL) が見える）で、ツール呼び出しはどれも同じ 1 行と JSON、長い本文は 60vh の箱の中でさらにスクロールします。直す中身は決まっているので、その見せ方を軸ごとに選んでください。

  • Markdown を描く：見出し、太字、リンク、箇条書き、番号付き、表、引用、コードブロック（言語名とコピーのボタン）。
  • ツールを種類ごとに描き分ける：Edit / MultiEdit は赤と緑の差分、Write はパスとコード、Bash はコマンドと出力、Read はパスと行の範囲、WebFetch / WebSearch は URL や検索語と結果、その他は整形した引数。どれにもツール名の札を付ける。
  • 入れ子のスクロールをやめ、長いものは畳んで「全文を表示」。
  • 本文の中の検索（⌘F の欄、前へ・次へ、一致の印）と、検索の結果から開いたときの一致箇所の強調。

今比べるための現在の描き方

Markdown は太字とコードだけ効き、表と箇条書きは記号のまま。ツールは JSON のまま。

MClaude の返答の器

同じ Markdown を 3 つの器で描いています。利用者の指示は、どの案でも右寄せの青い吹き出しのままです。

Tツール行の密度

返答の間に Read、Edit 2 回、Bash 2 回（うち 1 回は失敗）が続く場面です。Edit の 1 つを開いたところを描いています。

Kツール名の札

札の形だけを変えています（行は T1）。K1 は種類を 4 つの色に分けます（読む＝青、書く＝緑、実行＝杏、web＝紫、その他＝灰）。

D差分の見せ方

Edit を開いたときの中身です。変わっていない行は前後 2 行だけ見せ、間は「⋯ 行」で畳みます。

見本ツールの種類ごとの中身

選んだ札（K）と差分（D）で描いた、種類ごとの開いた中身です。どれも行を押すと畳めます。選ぶものではありません（直したい所があれば種類の名前で伝えてください）。

F長い本文と長い出力の畳み方

左は 64 行ある Claude の返答、右は 212 行ある Bash の出力です。どの案も面の中の入れ子のスクロールはやめ、開くと面そのものが伸びます。

S本文の中の検索（⌘F）

「バリデーション」で探して、12 件中 3 件目にいるところです。今いる一致は濃い黄と杏の縁、ほかは淡い黄。畳んだツールの中に一致があれば、行に件数を出します。

J検索の結果から開いたとき

セッションの一覧の検索（「パスワードの条件」）から、このセッションを開いた直後です。「もう一度」で着いた瞬間の動きを繰り返せます（reduced motion では動かさず、印だけを残します）。
