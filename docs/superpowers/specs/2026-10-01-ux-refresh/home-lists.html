ホームと一覧の細部

何を決めるための試作か

ホーム、プロジェクト、セッション一覧の小さな直しを並べました。方向（何を出すか）は決まっていて、ここではどう見せるかを選びます。

直すことは、「最近」の行にプロジェクト名／カードの抜粋から雑音を除いて要約を優先／「ここで新規」は乗せたときだけ／一覧の 2 段目に要約の状態（「詰まっている」「中断」だけ色）と「本文なし」の印／「確かめる」を実行中の下へ移して 3 件で畳む／見出しに「すべて見る →」／何も動いていないときの 1 行／プロジェクトの状態を日本語に／ヘッダーの使用率ゲージに見出し、です。

カードは乗せると変わります。一部の図は「乗せた状態」を固定して描いています（右下に注記）。中身はすべて架空です。

  • A1名前の右に小さく（一覧画面と同じ）
  • A22 段目の頭に「プロジェクト ·」
  • A3右端の時刻の上
  • B 2 段目の要約の状態と「本文なし」
  • B12 段目の頭に札。色は「詰まっている」「中断」だけ
  • B22 段目の末尾に一語。本文なしは行ごと薄く
  • B3左端の細い帯と、右端の一語
  • C プロジェクトのカード
  • C1要約を 2 行。「ここで新規」は乗せたときだけ右下に
  • C2パスを外して要約を主役に。乗せると右上に ＋
  • C3乗せると下端から「＋ ここで新規」の帯が上がる
  • D 状態の名前
  • D1進行中 / 保留 / 完了 / 保管
  • D2進めている / 止めている / 終えた / しまった
  • D3アクティブ / 一時停止 / 完了 / アーカイブ

A「最近」の行のプロジェクト名

ホームの「最近」はプロジェクトをまたいで並ぶのに、どのプロジェクトかが出ていません。2 段目は B1 で描いています。

今名前と要約だけ

同じ名前の会話が別のプロジェクトにあると区別できない。

A1名前の右

セッション一覧の行と同じ形。画面をまたいで揃う。

名前が長いと押し出されて見えなくなる。

A22 段目の頭

名前の長さに左右されず、いつも同じ位置に出る。

要約の頭が右へずれ、読める文字が減る。

A3時刻の上

右端の空いた場所に置く。左の読み始めを邪魔しない。

右端は目が行きにくく、名前との対応を取りにくい。

B2 段目の要約の状態と「本文なし」

要約には状態があります（完了、進行中、調査中、詰まっている、中断）。色を付けるのは手を貸すべき「詰まっている」と「中断」だけで、ほかは灰色の文字です。「本文なし」は、Claude Code の掃除で会話の本文が消え、索引の記録だけが残っている行です。一覧画面の幅で描いています。

B1頭に札

2 段目の頭に小さな札。色の札が 2 種しかないので、一覧を流し見ると色の行だけが目に止まる。本文なしは右端に枠だけの札。

B2末尾に一語

要約を読み終えたところで状態が分かる。札を使わないので静か。本文なしの行は文字ごと薄くし、名前の横に印。

要約が長いと末尾が省略されて状態が見えない（状態は省略しない側に置く必要がある）。

B3左の帯と右端の一語

行の左端に 3px の帯。右端の時刻の上に状態の一語。2 段目は要約だけに戻る。

左端の状態の点（作業中など）と帯が近く、2 つの状態が並んで紛らわしい。

Cプロジェクトのカード

抜粋には、最後の利用者の発言がそのまま出ています。貼った HTML、[Pasted text #1 +5 lines]、exit、/init のような雑音は除き、要約があれば要約を優先します。要約が無いときは、雑音を除いた最後の意味のある発言。どちらも無ければ「まだ要約がありません」。各案の 2 枚目は乗せた状態を固定して描いています。状態の名前は D1 で描いています。

除くもの例（今の抜粋）代わりに出すもの
HTML やコードだけの発言<input class="txt1" id="PhoneNo" style=…要約「トークン更新の競合を調べている」
貼り付けの置き換え表記[Pasted text #1 +5 lines]要約「導入の節を書き直した」
終わりの打鍵exit、/exit、q要約「引数の整理を終え、v2.0 を出した」
スラッシュコマンドだけ/init、/clear、/compact直前の意味のある発言「画像の圧縮率を比べたい」
URL だけhttps://example.com/…要約か、その前の発言

今パスと生の抜粋、いつも「ここで新規」

12 枚すべてに同じボタンが並び、札（active）も全部同じ。

C1要約 2 行、乗せると右下にボタン

今の配置のまま中身を替える。パスは 1 行残す。ボタンは乗せたとき・キーボードで届いたときだけ。

C2要約が主役、右上に ＋

パスは外し（乗せると吹き出しで見える想定）、札も点と小さな文字に。カードの背が低くなり、1 画面に多く並ぶ。

＋ だけでは何が起きるか分かりにくい（吹き出しで「ここで新規」と言う）。

C3下端の帯

乗せると下端から帯が上がる。押せる範囲が広く、何をするかも言葉で分かる。

動きが大きく、カードの間を横切るたびに帯が上下する。

Dプロジェクトの状態の名前

今は群の見出しが「Active」、札が「active」、ほかは「Paused」など英語です。一覧の見出し、カードの札、札を押して出る一覧の 3 か所で同じ語を使います。

D1進行中 / 保留 / 完了 / 保管

2 文字でそろい、札が短い。

D2進めている / 止めている / 終えた / しまった

アプリのほかの文言（「待っている」など）と同じ話し言葉。

札が長く、カードの名前を押す。

D3アクティブ / 一時停止 / 完了 / アーカイブ

今の英語をそのまま日本語にした。慣れた人の読み替えが要らない。

カタカナと漢字が混ざる。

E「確かめる」の置き場と畳み方

今は要対応のすぐ下にあり、件数が多いと実行中の札を画面の外へ押し出します。実行中の札の下へ移し、3 件で畳みます。見出しの「すべて見る →」は H1 で描いています。

E13 件と「ほか 4 件」

今の札の形のまま 3 件だけ出し、4 件目からは 1 行にまとめる。押すとその場で開く。

E23 列の札

実行中と同じ 3 列にし、高さを抑える。右端の「+4」で残りへ。

1 件の文が短くしか出ない。

E31 枚にまとめる

1 枚の札に 3 行。確定（✓）と却下（×）はアイコンにして、行を 40px に詰める。

アイコンだけでは確定と却下を取り違えやすい（吹き出しで補う）。

F何も動いていないとき

今は実行中の区画ごと消え、「最近」がいきなり始まります。空であることと、次の一手を出します。

F11 行と新規ボタン

高さ 44px の 1 行。場所をほとんど取らない。

F2点線の空の札

実行中の札が入る場所を点線で示す。札が現れる位置が先に分かる。

何も無いのに 128px を使う。

F3続きから

要約が「中断」の最近のセッションを 1 件出し、再開を勧める。新規も並べる。

中断が無いときは F1 の形に戻る（2 つの形を持つ）。

Gヘッダーの使用率ゲージの見出し

今は棒 2 本と数字だけで、どちらが 5 時間でどちらが週かが分かりません。

今棒と数字だけ

G1棒の左に見出し

「5 時間」「週」と読める。1 本あたり 40px ほど伸びる。

G22 段

上に見出しと数字、下に棒。横幅は今とほぼ同じ。

10px の字になり、読みにくい。

G3数字の後ろに短い見出し

「28% 5h」「55% 週」。幅の増えが最小。

「5h」は略語で、初めてだと読めない。

G41 つの錠剤と吹き出し

2 本を重ねた小さな錠剤にし、乗せると見出し・数字・戻る時刻（「5 時間の枠は 16:00 に戻る」）が出る（この図では出したまま）。

乗せないと数字が読めない。

H「すべて見る →」

ホームの「最近」「プロジェクト」「確かめる」の見出しから、それぞれの一覧画面へ。

H1見出しの右端

一覧の右上の角に「すべて見る →」。一覧の幅によらず同じ位置。

H2件数がリンク

「最近 412 →」。部品が増えない。

押せることが分かりにくい。

H3一覧の下端

読み終えたところにある。スクロールの終わりと重なる。

一覧の中でスクロールすると最後まで行かないと見えない。
