設定の組み直し

何を決めるための試作か

いまの設定は 11 の節が縦に長く並ぶ 1 枚です。これを「必須」「連携」「要約器」「同期」「情報」の 5 群にまとめ、目次を付けます。パスの欄は欄を出たら保存し（保存ボタンをなくす）、欄の下で見つかったかを言います。端末で打つコマンドは hangar … にそろえてコピーボタンを付け、参加トークンには残り秒数とコピーを付けます。

この頁で決めるのは見せ方で、軸は 5 つです。A 目次の形、B 検証の出し方、C 保存の知らせ方、D コマンドの見せ方、E 参加トークン。A の窓は中をスクロールでき、目次も押せます。C は欄を書き換えて外へ出ると動きます。E の秒数は実際に減ります。中身はすべて架空です。

A目次の形

中身はどの案も同じ（検証は B1、コマンドは D1 で描いた）。群の見出しの右の札は、その群に直すものがあるかを言う（連携に「1 件」＝外のターミナルが未導入）。窓の中はスクロールできます。

A1左に固定の目次

1 枚の長い頁のまま、左に目次を固定する。スクロールすると今の群が灯り、押すとそこへ滑る。群の下に節の名前も小さく並べる。

アプリのサイドバーと合わせて左に列が 2 本並ぶ。

A2上のタブ

切り替えの帯で 1 群ずつ出す。1 群は長くても 2 画面ほどで、目的の欄がすぐ見える。

全体を一度に見渡せない。探す欄がどの群にあるか知っている必要がある。

A3大きな見出しだけ

部品を増やさず、群の見出しを大きくして区切る。先頭のチップで飛ぶ。今の形からの変化が最も小さい。

スクロールすると飛び先が見えなくなる。

A4左の一覧と群の頁

macOS のシステム設定の形。各群の一行目に要点（「tmux・claude・Node」）と、直すものの数を出す。

群の頁が短いと右の余白が目立つ。一覧の側が目次と頁の 2 役を持つので、戻る先が分かりにくい。

B検証の出し方

パスの欄は、外へ出た時点でそのパスを実行して確かめます。見つかったら「✓ パス（版）」、見つからなければ「✗ 見つかりません」と直し方（コピーできるコマンド）。code は無くても動くので、赤でなく注意の色にします。

B1欄の下に 1 行

欄と結果が縦に並び、長いパスもそのまま読める。直し方も同じ行に置ける。

欄ごとに 1 行ずつ背が伸びる。

B2欄の中に札

欄の中の右端に「✓ 3.4」。見つからないときだけ下に直し方の行が出る。正常なときは背が伸びない。

札の分だけ欄の文字が切れやすい。

B3ラベルの右端

ラベルの行の右端に点と「3.4 で動きます」。欄の形は今のまま。

欄から目が離れた位置にあり、見落としやすい。

B4表にする

道具・パス・状態の 3 列。準備が揃っているかを縦に一目で確かめられる（初回の確認リストとも形がそろう）。

ターミナルアプリの切り替えは表から外に出る。

C保存の知らせ方

保存ボタンはなくし、欄を出た時点（Tab、ほかを押す、Enter）で保存します。欄を書き換えて外を押してください。 tmux を含まないパスにすると、保存はされたうえで検証が ✗ になります。

C1欄の横の ✓

保存した欄の右に「✓ 保存しました」が 2 秒出て消える。どの欄が保存されたかが確か。

欄の右に場所を空けておく必要がある。

C2右下の通知

アプリの通知の形で「tmux のパスを保存しました　取り消す」。書き間違いを戻せる。

欄から目が離れる。続けて何欄も書くと通知が積もる。

C3欄の縁が灯る

縁が一度だけ緑に光って戻り、ラベルの横に「保存済み」が残る。動きで知らせるので文字が少ない。

動きを減らす設定では光らず、「保存済み」の文字だけになる。

C4見出しの右に状態

文書の自動保存と同じく、節の見出しの右に「保存しています…」→「すべて保存済み · 14:03」。1 か所だけ見ればよい。

どの欄が保存されたかは言わない。

Dコマンドの見せ方

いまは npm run hangar -- mcp install のように開発用の書き方が出ています。すべて hangar … にそろえ、コピーを付けます。例は連携の群の 3 つ。

D1薄い地のコード

今の snippet の形に、右端のコピーを足しただけ。

D2墨の板

アプリの端末と同じ墨色。「ターミナルで打つもの」と一目で分かる。

白い面の上で目立ちすぎる。

D3状態と一体

「まだ登録されていません」とコマンドを 1 枚に。済んだ節は緑の 1 行に縮み、外し方だけ残す。

節ごとに状態を読み取れる必要がある（MCP の登録は今は読んでいない）。

E参加トークン

押すと出て、120 秒で消えます。いまは「120 秒で自動的に消えます」と書くだけで、あと何秒かもコピーもありません。この試作では 30 秒から数えます。

（全案の秒数を戻す）

E1秒数の輪

輪が減り、残り 10 秒で色が替わる。コピーはすぐ横。

E2減る棒と文

トークンの下に細い棒と「あと 27 秒で消えます」。言葉で読める。

E3伏字でコピー

画面には伏字で出し、コピーだけで渡せる。画面共有や肩越しに見られても漏れない。「見る」で表示。

写し間違いを目で確かめにくい。
