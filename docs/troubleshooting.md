# 困ったとき

- **アプリが起動しない。**
  起動の記録 `~/.agent-hangar/desktop.log` の末尾を見てください。
- **読み込み画面が、Node が見つからない、または版が合わないと告げる。**
  Node 22.14 以上を入れてから開き直すか、画面の「node を選ぶ…」（Windows は「node.exe を選ぶ…」）で入れた Node を選んでください（macOS は「[前提](install.md#前提)」、Windows は「[Windows の前提](install.md#windows-の前提)」と「[Node の探し方](install.md#node-の探し方)」）。
- **初めて開くときに「"Hangar" は開いていません」と出る（macOS）。**
  手順の 3 段目の順で開きます（「[手順](install.md#手順)」）。
- **ローカルネットワークや、ファイルとフォルダの許可をもう一度求められる（macOS）。**
  v0.1.0 から入れ替えた初回だけ起きます（「[v0.1.0 からの移行](install.md#v010-からの移行)」）。
- **Windows の SmartScreen が止める。**
  「詳細情報」を押して「実行」を選びます（「[インストーラで入れる](install.md#インストーラで入れる)」）。
- **ブラウザで開いたら 401 になる。**
  鍵の無い URL は 401 を返します。
  `hangar url` で鍵付きの URL を出してください（「[画面を開く](usage.md#画面を開く)」）。
- **クッキーを消したら開けなくなった。**
  `hangar open` でもう一度開き直してください。
- **tmux（Windows は psmux）、`claude`、git の有無を確かめたい。**
  `hangar setup` が報告します。
  ホームの「セットアップの確認」にも出ます。
  入れたあとは「再確認」を押します。
- **Claude Code の新しい版で、知らない形式が出たと知らされた。**
  `~/.agent-hangar/compat.json` に記録され、設定の「連携」の節と、初回の確認リストに出ます（「[できること](usage.md#できること)」）。
- **連携の書き込みで、ファイルが変わっていると止まった。**
  「再読み込み」で見直してください（「[アプリのボタンで書くとき](usage.md#アプリのボタンで書くとき)」）。
- **アカウントの共有のリンクが実ファイルになり、起動や再開ができない。**
  中身が同じなら hangar が自動でリンクに戻します。
  違うときは、失敗の知らせか設定のアカウントの行の「修復…」で、どちらを使うかを選んでください（「[ファイルの扱い](files-and-network.md#ファイルの扱い)」）。
- **エラーや注意の原因が分からない。**
  その場で直すボタンが無いエラーと注意には「エージェントで調査…」があります。
  押すと、内容を入れた新しいセッションのダイアログが開き、エージェントが原因を調べて、承認を得てから直します。
- **同期が止まった。**
  無料枠の上限に達したときは、次の UTC の 0 時まで止まり、自動で戻ります（「[クラウド同期](cloud-sync.md#クラウド同期上級者向けのベータ)」）。
