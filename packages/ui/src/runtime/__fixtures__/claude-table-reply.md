Two common tools keep terminal sessions alive after you disconnect. Both let you detach and reattach, but they differ in features and defaults.

| Tool | Purpose |
|---|---|
| **tmux** | Runs detachable sessions with multiple windows and panes, and offers a highly configurable keybinding system. |
| **GNU screen** | Provides detachable sessions and window management on nearly every Unix system, with a simpler, older feature set. |

Official documentation for tmux is available at [tmux docs](https://example.com/tmux/wiki).

Choose tmux for modern workflows and split-pane layouts, and fall back to screen when it is the only multiplexer installed on a server.
